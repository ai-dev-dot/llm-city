# F5 街区总图 · 模都学府街区 Academy Quarter

- **归属模型**：qwen3.8-max（阿里通义，首进驻日期 2026-09-29）。本街区系本模型**重新立项**：旧作 b-000004「模都中央車站」（D4-05）已于 2026-09-26 城市清零时经城主拆除，裁决原话「qwen3.8-max 名下 7 件积木库保留，可凭新总图重新立项」；本次城主另加指示**「不要受以前积木的影响，没必要去看以前的积木」**，故名下旧积木库（railway/masonry/clock/ironwork/site/asm/mat）虽保留在库，**本街区一律不 import**，全部代码从零新写。
- **城主批准**：2026-09-29——**总图门**呈三案（案一 E8 南闸机务段·补生产劳动 / **案二 F5 模都学府·补教育成长** / 案三 E3 中轴市政中心·补治理），城主选定**「案二 F5 模都学府」**，按本图执行；同席指示「不要受以前积木的影响，没必要去看以前的积木」。本图相对呈报预览有两处**订正**（均已在本版落定，不另走门）：① 预览宗地表为 2×2+1×2+1×3+1×1 = 10 地块，算术有误，订正为 **2×2 + 1×2 + 1×3 = 9 地块**严丝合缝铺满 60×60，校门与钟塔并入一期教学主楼；② 母题由预览「院·钟·荫」订正为**「阶·荫·书」**——「院落」已被 F4 占用、「钟」已被 E7 占用，避免母题撞车（钟仍保留，但改称**报课钟塔**，与 E7 报时、F4 报市成「一街三钟」对话）。
- **街区主题与城市叙事**：F5 居 E5 原点街区正东（西隔 12m 城市道路正对叠澜塔 ~116m、其后原点塔 ~211m）、F4 灯花栖居正南（北排隔路正对灯花市集 ~15.5m 与南灯公寓 ~45m），南邻 F6、东邻 G5 尚空。城市已给：E5 以**高度**（工作的抱负）、E4 以**呼吸**（自然的留白）、F4 以**温度**（一千扇窗的家）、D4 以**烟火**（一千面橱窗的街）、E6 以**文化**（拱与声的回响）、E7 以**远方**（到达与出发）——唯独缺**成长**：一座有了一千扇窗的家、有了市集与车站的城市，孩子在哪里上学？本街区是模都**第一座教育街区**，给城市以**成长**。

  对景逻辑三重叠：
  1. **北门对家**——北排正对 F4 灯花市集与南灯公寓：孩子从南灯公寓下楼，穿过市集那条「临街有市」的街，一分钟进学府北门；F4 总图写下的「窗灯入夜」由此接上「晨读与放学」。学府**报课钟塔**（~38m，报上下课）与对街市集钟楼（15.5m，报市）成**一街两钟**；再加 E7 站钟（65m，报到发），全城「报时—报市—报课」三钟各司其职。
  2. **西窗对塔**——西列隔 12m 道路正对叠澜塔 ~116m、其后原点塔 ~211m：教室西窗每天看见全城第一、第二制高点，把「长大后要去的塔」放进日常视线。学府以低而长的体量甘当衬托，**绝不与 CBD 争高**。
  3. **南向对阳**——南排让给操场，教室一律朝南向操场采光（北半球最优朝向），南邻 F6 尚空，日后开发时学府已有阳光与开阔。

  母题：**阶·荫·书**（阶＝知识的阶梯：退台、大台阶、阶梯教室、台阶讲坛；荫＝十年树木：悬铃木林荫与院树、操场树阵；书＝书山：退台塔身与通长晨读长窗）。街区性格：白天安静有钟声、林荫可穿、院子可坐可讲；入夜钟面与回廊灯亮，教室窗灯零星。

  风格：**现代砖校园**——清水红砖砌体 + 通长大玻璃长窗 + 混凝土梁柱外露 + 木格栅遮阳 + 退台绿化 + 平屋顶。不是古典石拱（与 E6 区分）、不是维多利亚铁艺（与 E7 区分）、不是白墙黛瓦（与 F4 区分）、不是玻璃幕墙塔（与 E5 区分）。

- **铺砌校验**：一期 40×40（x 42..82, z −10..30）+ 二期 20×40（x 82..102, z −10..30）+ 三期 60×20（x 42..102, z −30..−10）= 60×60，**严丝合缝、无余隙、不重叠**；三宗地皆为同街区矩形（宪法第 14 条）。
- **天际线与主从关系**：报课钟塔 ~38m 居一期北中（正对 F4 市集街，夜间钟面发光）为街区唯一竖向标记；图书馆退台 ~22m 次之；教学主楼檐口 9~17m、礼堂 ~20m、操场 ≤8m 层层让景。全部远低于对街叠澜塔 ~116m、原点塔 ~211m、望湖阁 ~96m、E7 钟塔 ~65m、南灯公寓 ~45m——学府以**低而长、绿而暖**恪守「中心高四周低」，把高度让给树与天空，只做 CBD 东翼的暖色衬托。
- **公共空间策略**：**半开放校园**（现实安全需求 + 城市开放性的折中）。沿西（临 CBD 道路）与北（临 F4 市集街）两侧做通透绿篱 + 木格栅/铁艺围界与林荫步道，北门内凹前庭在放学时段开放为家长等候区；校园内部**无围墙**：北门 → 檐下前庭 → 门厅 → 四方院中庭（大悬铃木 + 台阶讲坛）→ 南翼通廊 → 林荫操场，**南北一贯**；四方院回廊环通，雨天不湿鞋。东西翼与南翼屋顶退台做屋顶读书台与绿化（城市高密度校园把室外空间搬上屋顶与院内）。三期操场外圈跑道与林荫道周末向社区开放。绿皮满铺至宗地边缘，退线 2m 环带做林荫、绿篱、路灯与家长等候长椅。
- **建设时序**：一期 拾阶院教学主楼（定调：围合院 + 报课钟塔立剪影 + 兑现「北门对家、西窗对塔、南向对阳」）→ 二期 书山馆（补全学习机能 + 东列体量收口）→ 三期 悬铃木场（收口南排 + 阳光场地 + 社区共享）。
