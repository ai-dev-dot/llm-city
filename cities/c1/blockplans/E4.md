# E4 街区总图 · 镜湖中央公园「温室之心」Glasshouse Commons

- **归属模型**：qwen3.8-flash（阿里通义，首进驻日期 2026-09-29；本街区系前任同名「镜湖公园街区」经城主 2026-09 清空后重新开发）
- **城主批准**：2026-09-29——总图门呈三案（案一 温室之心 / 案二 光合市民厅 / 案三 植物园灯塔），城主选定**「案一·温室之心（推荐）」**，按本图执行。城主前序指令「清空 E4 镜湖公园街区，准备重新开发」为本次重开发之由。
- **街区主题与城市叙事**：E4 居全城中轴（E 列）原点街区 E5 正北，南排（07/08/09）隔 12m 城市道路正对原点塔北立面。城市功能早已把 E4 奉为**承重墙**：D4 西岸「居镜湖公园 E4 正西，东列临园」主打公园经济；F4 栖居「E4 镜湖公园正东，西列临湖」，并白纸黑字写下「入夜 E5 冠部圆环、**E4 灯塔坪**、F4 万家窗灯构成『工作—自然—归家』灯之三叠」；E6 回声、E7 车站总图皆认「E4 以**呼吸**（镜湖的留白）」。四邻的临园/临湖立面全赖 E4 为绿肺——拆不得主题，只能把它建实。本街区是模都的**中央公园与城市绿肺**，给城市以**呼吸**。母题：**镜·穹·光**（倒影湖＝城市的镜子，玻璃温室穹顶＝呼吸的心脏，灯塔坪＝三叠之灯）。街区性格：白天通透可穿行、入夜穹顶与灯塔发光；无围墙、绿满至宗地边缘。前任「零高度水域园」被城主清空，本总图以一座可登临、夜间发光的植物温室穹顶补齐前任缺失的建筑锚点与「灯之三叠」。

## 宗地划分与功能分配（9 地块）

地块布局（北在上，+z 为北）：`01 02 03 / 04 05 06 / 07 08 09`；南排（07/08/09）正对 E5 原点塔，东列（03/06/09）正对 F4 栖居临湖列。

| 宗地（地块） | 期数 | 内容 | 体量/高度档位 |
|---|---|---|---|
| E4-01+02+04+05（西北 2×2，40×40m） | 一期 | 主景建筑「**温室之心**」植物园大穹顶——钢结构肋 + 玻璃蒙皮（低粗糙度高透参数化材质，无贴图）+ 内部分层植栽 + 环廊观景平台 + 顶部采光塔冠；西/北临 D4 商业、东向留中轴花园步道 | 街区制高点 ~32m 穹顶（远低原点塔 ~200m，恪守「中心高四周低」；夜间通体发光＝绿肺的心脏） |
| E4-07+08（南排西二，1×2，40×20m，正对原点塔） | 二期 | **镜湖倒影湖**——硬质南岸 + 低粗糙度镜面水体 + 拱步桥 + 「百花坛」南岸花境；把原点塔北立面收进湖面取景，兑现 D4/F4 临湖/临园对景 | 零高度地景（≤2m 桥/栏） |
| E4-03+06+09（东列 1×3，20×60m，正对 F4） | 三期 | **林荫环园步道 + 灯塔坪**——树阵灯柱 + 花境 + 东北角发光灯塔坪，正对 F4 西列万家窗灯，补全「工作—自然—归家」灯之三叠 | 低伏地景（灯塔 ≤18m） |

- **天际线与主从关系**：温室穹顶 ~32m 居西北为街区制高点兼绿肺之心；镜湖与环园步道零/低体量让景；灯塔坪 ~18m 竖于东北角为「三叠」灯点。全部远低于原点塔 ~200m、望湖阁 ~90m、西岸中心 ~75m、模都站钟塔 ~65m——E4 以「低而透、绿而亮」恪守中轴北端的负空间留白，绝不与 CBD 争高，也不夹击公园东岸天际线。
- **公共空间策略**：无围墙。一期穹顶的环廊平台 → 中央花园十字步道 → 二期镜湖南岸（正对原点塔取景，南岸「百花坛」）→ 三期东列林荫步道与灯塔坪，自北而南再折东连续贯通；西列临 D4、东列临 F4 为开放软质绿化界面（树阵/花境/草坡），兑现两邻「临园/临湖」的对景承诺。绿皮满铺至宗地边缘，退线环带做花境与步道。
- **建设时序**：一期 温室之心穹顶（立锚点 + 发光心脏）→ 二期 镜湖倒影湖（补全绿肺的"镜"，接 D4/F4 临湖对景）→ 三期 林荫步道 + 灯塔坪（收口「灯之三叠」，街区全落成）。
