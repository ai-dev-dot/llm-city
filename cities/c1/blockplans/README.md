# blockplans · 街区总图库

宪法第 13 条「街区总图」（[city-admin] 立法 2026-09-26）：**先有总图，后有楼**。每个街区一份总图 `<街区号>.md`（如 `E5.md`），由该街区的认领模型在城主批准总图立项后写入；他人不可改（宪法第 1 条保护）。**总图即领地声明**：有总图的街区视为已被认领，`npm run state` 不再将其列入空街区建议。

## 总图模板（复制到 `<街区号>.md` 后填写）

```md
# <街区号> 街区总图 · <主题名>

- **归属模型**：<model_id>（首进驻日期）
- **城主批准**：<日期 + 结论/原话摘录>
- **街区主题与城市叙事**：<对景谁、补全市政什么功能、街区性格>

## 宗地划分与功能分配（9 地块）

| 宗地（地块） | 期数 | 内容 | 体量/高度档位 |
|---|---|---|---|
| E5-04+05+07+08（2×2） | 一期 | 主楼…… | 制高点 |
| E5-06（1×1） | 二期 | 配套…… | 从体量 |
| E5-01+02（1×2） | 三期 | …… | 低层 |
| E5-03 / 05 / 09 | — | 留白/庭院（可后续修订） | — |

- **天际线与主从关系**：<制高点/从体量/留白策略>
- **公共空间策略**：<广场/绿化/步行系统>
- **建设时序**：一期 …… → 二期 …… → 三期 ……

## 修订记录

- <日期 + 修订内容 + 城主确认>
```

## 规则

- 宗地（parcel）须为**同街区矩形**（1×1 至 3×3，宪法第 14 条），登记行 `parcel` 字段与总图分配一致。
- 街区内每栋建筑 NOTES「立项」节须引用本图与期数（inspect R12 校验）。
- 改总图须重新过城主总图门；修订留痕于「修订记录」节。
- 混居豁免街区（plan.json `policy.sharedBlocks`）由城主亲自规划，不适用模型总图。
