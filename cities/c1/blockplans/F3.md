# F3 街区总图 · 揽月街区 Lanyue Quarter

- **归属模型**：kimi-k3（月之暗面 Moonshot AI，首进驻日期 2026-10-06）
- **城主批准**：2026-10-06——**资格门**批复「批准入伙」（kimi-k3 自登记 models.json 含 moonshot 厂商，城主以 gen-plan 将 kimi-k3 加入 allowedModelIds）；**总图门**首呈三案（案一 F6 望月天文街区 / 案二 C5 议政环 / 案三 D6 康养林），城主指示「kimi k3 是很多人心中的国产大模型王者 top1，你负责的街区要有可能成为这座城市地标——比如最顶级的豪宅、最顶级的写字楼、最顶级的酒店，一定要最顶级、可以成为城市名片，重新提议」；二次呈三案（案一 F3 揽月街区 / 案二 D3 云上门厅 / 案三 G4 云顶荟），城主选定**「案一 F3 揽月街区（推荐）」**，按本图执行。
- **街区主题与城市叙事**：城市已给：E5 以**高度**（工作的抱负）、E4 以**呼吸**（自然的留白）、F4 以**温度**（一千扇窗的家）、D4 以**烟火**、E6 以**文化**、E7 以**远方**、F5 以**成长**、G5 以**创造**、D5 以**健康**、E3 以**博览**、C4 以**记忆**——唯独缺**巅峰**：一座城市把最好的一切集中在一处的那个门牌。本街区是模都**第一座经典顶奢街区**，给城市以**巅峰**。

  选址黄金三角（顶奢亘古不变的地段逻辑：公园 + 会展 + 富人区，现实原型即中央公园南的 Plaza、香港中环的文华东方）：
  1. **西南对镜湖**——西南角与 E4 镜湖公园东北角对角相望：酒店每一扇西南窗都收湖景，「公园是酒店的延伸前庭」。
  2. **西轴对博览**——西缘隔 12m 城市道路正对 E3 博览中心东排：会展的人流、盛典的宾客过街即入大堂，「博览在办盛会，揽月在安放盛会之后」。
  3. **南排续灯花**——南缘正对 F4 灯花栖居北排（望湖阁 ~96m）：F4 是一千扇窗的家，F3 是一扇窗的巅峰——城市给过「归家」，现在给「登堂」。

  与 E5 错位（不撞车、不压高）：叠澜塔（~116m）是现代天际设计酒店，揽月是**石材 + 香槟铜 + 月牙穹顶冠**的经典大饭店——old money 的恒久奢华对新锐设计；主塔 ~105m 甘居原点塔 211m / 叠澜塔 116m 之下，与望湖阁 96m / 求索塔 95m 同档，恪守「中心高四周低」——**顶级靠品质，不靠压高**。

  母题：**月·阙·云**（月＝月之暗面的身份：月牙穹顶冠、月相铺装、映月池水中月——Moonshot 中文正解「可上九天揽月」，模型身份即顶奢品牌；阙＝经典三段式塔身、石材竖梃的门阙感；云＝云顶餐厅、云顶豪宅，层层退台如云阶）。街区性格：白昼克制恒久——月光石灰白、香槟铜檐、深拱窗；入夜一层暖金洗墙、月牙冠微光、窗灯疏落——**全城最克制、也最贵的一道光**。

  风格：经典顶奢（Beaux-Arts 三段式 + 装饰艺术线脚）——月光石 #E8E2D4 竖梃、香槟铜 #B08D57 檐口线脚、深拱窗 #2A3F54、穹顶铜金。与 E5 琥珀金镜（现代玻璃）、F4 深蓝白框（居住社区）、E6 石拱（粗粝文化）、G5 银蓝科技明确区分。

- **天际线与主从关系**：主塔 ~105m 居西南 C 位为街区制高点（全城第四高，甘居原点塔 211m / 叠澜塔 116m 之下）；揽月阁 ~75m 居东南为从体，双塔西南—东南错开不并立；月庭 ~15m 北排压低做裙边；揽月台通透留白。高塔让出东北 = 从北路看街区呈「南起北伏」的谦逊轮廓，不与 E5 双塔争锋。
- **公共空间策略**：无围墙。映月池前庭（一期，酒店与城市共享的静水广场）→ 月庭拱廊骑楼（三期，全天候步行商业界面）→ 揽月台草坪（四期，街角花园）形成自西南向东北渗透的公共序列；环街区月相铺装步道串联，人行穿越自由。
- **建设时序**：一期 揽月大酒店（立地标、定街区性格）→ 二期 揽月阁（续天际线、补顶级居住）→ 三期 月庭（补商业与会所功能）→ 四期 揽月台（花园收口，街区全落成）。
