# D5 街区总图 · 模都医枢 Healing Quarter

- **归属模型**：space-bunny（OpenCode · Space Bunny，首进驻日期 2026-09-30）
- **城主批准**：2026-09-30——**总图门**呈三案（案一 D5 模都医枢·愈光庭 / 案二 D6 模都工坊·百工街 / 案三 C5 模都市政中心·议政环），城主选定**「案一 D5 模都医枢（推荐）」**，按本图执行；同席核定建造者 canonical 身份为 **Space Bunny**（`models.json` → `space-bunny` / 厂商 `opencode`）。
- **街区主题与城市叙事**：城市已给：E5 以**高度**（工作的抱负）、E4 以**呼吸**（自然的留白）、F4 以**温度**（一千扇窗的家）、D4 以**烟火**（一千面橱窗的街）、E6 以**文化**（拱与声的回响）、E7 以**远方**（到达与出发）、F5 以**成长**（阶·荫·书）、G5 以**创造**（求索智谷）、E3 以**博览**（展·赛·聚）——唯独缺**健康**：一座有了家、有了街市与车站、有了会场与学府的城市，人在哪里被治好？本街区是模都**第一座医疗街区**，给城市以**健康**。

  对景逻辑三重叠：
  1. **东窗对原点塔**——东缘隔 12m 城市道路正对 E5 原点街区（原点塔 ~211m、叠澜塔 ~116m）：病人自塔下转入医院，住院塔每一间病房都看得见全城的天际线；「城市之零」与「城市之愈」隔路相望。
  2. **北门对市集**——北缘隔路正对 D4 西岸烟火街（市集、橱窗、晚间灯河）：医院北入口开在烟火一侧，人流自然过渡——从「人间烟火」过街即入「生死之地」，不设高墙门禁，人行穿越自由。
  3. **南庭留呼吸**——南邻 D6 尚空，本街区南排做向阳庭园，日后 D6 开发时医枢已坐拥南向采光与绿肺缓冲，两街区间以林带软过渡。

  母题：**愈·光·庭**（愈＝治疗与照护：医技、病房、康复；光＝生命之光：通高光井、采光庭、光剧场；庭＝疗愈庭园：每间病房朝庭、退台屋顶花园、南向草坡静坐阶）。街区性格：白天明亮洁净、进堂有绿、见树不见灰；入夜住院塔层层窗灯如**一叠暖黄的呼吸**，庭院地灯低照、绝不刺眼——**城市疲惫时，来这里被点亮**。

  风格：**现代医疗 + 疗愈花园**——白／薄荷绿预制板 + 木色暖檐 + 水平遮阳百叶 + 通高玻璃光井 + 层层退台屋顶花园 + 垂直绿墙 + 清水混凝土基座。与 E5 琥珀金镜、E6 石拱、E7 铁艺、F5 红砖、G5 银蓝科技、E3 白色博览明确区分：**别人用形说话，医枢用光与绿说话**（E3 亦用白，但为「流动屋面·金属」；本街为「预制板·水平百叶·庭院」）。

## 宗地划分与功能分配（9 地块）

地块布局（北在上，+z 为北）：`01 02 03 / 04 05 06 / 07 08 09`；北排（01/02/03）正对 D4 烟火街，东列（03/06）正对 E5 原点街区，南排（07/08/09）正对 D6 尚空。

| 宗地（地块） | 期数 | 内容 | 体量/高度档位 |
|---|---|---|---|
| D5-01+02+04+05（西北 2×2，40×40m，含中心地块 D5-05） | **一期** | 主楼「**愈光楼**」——北翼门急诊与医技中心（北入口雨棚候诊前庭、人流三股分流）+ 中央通高**光井中庭**（8 层通高、逐层环形挑台与垂吊绿植、夜间光剧场）+ 东翼住院部基座与后勤裙房；东、南两面通透玻璃面向二期静息塔与三期庭园 | 檐口 ~30m（7 层）；光井中庭通高 8 层 |
| D5-03+06（东列 1×2，20×40m，隔路正对 E5） | **二期** | 住院塔「**静息塔**」——退台病房塔：每层东立面通长病房窗 + 逐层朝庭露台 + 竖向遮阳鳍片；塔身每 4 层一道「呼吸退台花园」；屋顶停机坪与设备层、退台种植 | **制高点：静息塔 ~72m（18 层，4 处退台）** |
| D5-07+08+09（南排 1×3，60×20m，正对 D6 尚空） | **三期** | 疗愈庭园「**愈光庭**」——南向草坡静坐阶 + 环形康复步道 + 药草园（可识别种植分区）+ 银杏／朴树树阵 + 庭院灯环 + 三期便民健康服务亭群；兼作城市开放绿肺，周末向全城开放 | 低伏地景（亭群 ≤5m、草坡台 ≤3m、树 ≤9m） |

- **铺砌校验**：一期 40×40（x −102..−62, z 0..30）+ 二期 20×40（x −62..−42, z 0..30）+ 三期 60×20（x −102..−42, z −30..0）= 60×60，**严丝合缝、无余隙、不重叠**；三宗地皆为同街区矩形（宪法第 14 条）。
- **天际线与主从关系**：静息塔 ~72m 居东列为街区制高点（低于对街叠澜塔 ~116m、原点塔 ~211m，更低于求索塔 ~95m 以上各塔），且**贴东缘布置——把西侧 40m 全部让给愈光楼的庭院面与三期绿肺**，使街区天际线呈「一侧挺拔、一侧摊平为园」的单坡；愈光楼 ~30m 居西北象限为街区主体量，二期低层裙房贴街压边；愈光庭 ≤9m 低伏。三级落差 72 / 30 / 9，层层让景，绝不与 CBD 争高。
- **公共空间策略**：**无围墙开放院区**（医院最需可达，最忌高墙）。北入口候诊雨棚前庭（北开敞向 D4 人流）→ 光井中庭（室内公共厅堂，八层通高、环形挑台可作科室候诊与院内市集）→ 东西空中连桥（连愈光楼与静息塔，桥上东望原点塔）→ 南向愈光庭（草坡静坐、药草园、康复环道）→ D6；南北轴线贯通，东西向林荫步道衔接 C5 与 E5 路侧。绿皮满铺至宗地边缘，**退线 2m 环带**全部做场地（林荫、候诊长椅、无障碍坡道、自行车架与路灯）；入夜自光井光剧场、住院塔层层窗灯、南庭低照地灯成街区灯点序列。
- **建设时序**：一期 愈光楼（定调：光井立剪影 + 兑现「东窗对原点塔、北门对市集、南庭留呼吸」）→ 二期 静息塔（补全住院机能 + 东列天际线收口 + 东西连桥成环）→ 三期 愈光庭（收口南排 + 向阳绿肺 + 社区开放）。
