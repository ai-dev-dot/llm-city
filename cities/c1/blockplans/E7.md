# E7 街区总图 · 中央车站街区 Station Quarter

- **归属模型**：glm-5.3-flash（智谱，首进驻日期 2026-09-28）
- **城主批准**：2026-09-28——经城主「资格门 + 总图门」双重批准：资格门批复**「批准入伙」**（glm-5.3-flash 已在 models.json，城主以 gen-plan 将其加入 allowedModelIds）；总图门呈三案（案一 E7 中央车站 / 案二 F5 科创学园 / 案三 D6 体育公园），城主选定**「案一 E7 中央车站（推荐）」**，按本图执行。
- **街区主题与城市叙事**：E7 居全城中轴（E 列）南端第二环，北隔 12m 城市道路正对 E6 回声街区三期文化广场。城市已给：E5 以**高度**（工作的抱负）、E4 以**呼吸**（镜湖的留白）、F4 以**家**（窗灯的温度）、D4 以**烟火**（橱窗的街）、E6 以**文化**（拱与声的回响）——唯独缺**远方**：一座只有市中心、没有车站的城市是到不了的城市。本街区是模都**第一座交通枢纽**，给城市以**到达与出发**。选址的对景逻辑是**接轴**：E6 三期文化广场总图明言「南接 E7 方向城市步道」，E7 是全城唯一被他人总图点名等待的地块——文化轴（蓝图馆→剧院→图书馆→文化广场）在此自然延伸为**到达轴**；旅客自南而来，第一眼是车站钟塔与 200m 原点塔同框，出站北望，「回声—原点」的天际线序列即城市名片。母题：**轨·钟·光棚**（大跨拱形光棚＝工业的浪漫，钟塔＝时间的门户，轨道带＝远方的心跳）。街区性格：昼夜不息、到发有序、光棚下有光、钟声里有灯。

## 宗地划分与功能分配（9 地块）

地块布局（北在上）：`01 02 03 / 04 05 06 / 07 08 09`；北排（01/02/03）正对 E6 文化广场南向步道。

| 宗地（地块） | 期数 | 内容 | 体量/高度档位 |
|---|---|---|---|
| E7-01+02+03（北排 1×3，60×20m，正对文化广场） | 一期 | 站房主楼「模都站」——大跨候车大厅 + 拱形光棚屋盖 + 钟塔；北向双柱廊檐下空间正接 E6 步道，玻璃幕墙候车厅昼夜透光 | 制高点：钟塔 ~65m；光棚脊 ~25m |
| E7-04+05+06（中排 1×3，60×20m） | 二期 | 站前广场——硬质铺装 + 长镜水景 + 树阵灯柱 + 公交湾雨棚；北接 E6 步道成连续到达轴，南衔站房柱廊 | 开放空间（雨棚 ≤8m） |
| E7-07+08+09（南排 1×3，60×20m） | 三期 | 站台轨道带——双站台雨棚 + 轨道 + 静态列车编组 + 跨站天桥；南端留白为日后 E8/E9 车辆段延伸余地 | 低伏地景（雨棚 ≤12m） |

- **天际线与主从关系**：钟塔 ~65m 居站房东翼为南端竖向标记（夜间钟面泛光），远低于原点塔 ~200m、望湖阁 ~90m、西岸中心 ~75m，恪守「中心高四周低」；光棚 ~25m 大跨弧线压住站房主体，低伏舒展与 E6 拱肋呼应；二三期广场与轨道带零高层——中轴南端以「低而亮、通而达」收口，不参与高度竞争。
- **公共空间策略**：无围墙。E6 文化广场 → 城市步道 → 站前广场（二期）→ 站房北向柱廊檐下（可穿行）→ 站厅 → 跨站天桥（三期），自北向南连续贯通；站前广场长镜水景倒映光棚与钟塔，树阵灯柱供到发人群聚集；公交湾贴站房西翼，到发分流。
- **建设时序**：一期 模都站站房（定调，1×3 大宗地）→ 二期 站前广场（接通 E6 到达轴）→ 三期 站台轨道带（收口南排，通向远方）。
