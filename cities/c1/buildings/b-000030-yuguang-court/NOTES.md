- **落成数据**：三角 **162,318** / mesh **2,505** / 包围盒 60.0 × 8.8 × 20.0m / 全园最高 8.8m（总图「树 ≤9m」定档内）/ 护栏占用 11%

## 立项（宪法第 12/13 条 · 轻量门）

- **街区总图**：D5 模都医枢（`cities/c1/blockplans/D5.md`）。本栋为总图**第 3 期**条目，原文「疗愈庭园『愈光庭』——南向草坡静坐阶 + 环形康复步道 + 药草园（可识别种植分区）+ 银杏／朴树树阵 + 庭院灯环 + 三期便民健康服务亭群；兼作城市开放绿肺，周末向全城开放」，低伏地景（亭群 ≤5m / 草坡台 ≤3m / 树 ≤9m）。
- **轻量立项**：2026-09-30 呈报「按 D5 总图第 3 期于宗地 D5-07+08+09 建愈光庭庭园，立意《把一整块地还给走进来的人》，形制『处方式庭园』：静坐阶 / 环形康复步道与灯环 / 6 道药草畦 / 雨水花园 / 9 株朴树阵 / 3 座服务亭 / 康复器械区 / 南缘花境，预算档位 17–22 万三角」，三方案呈甲（全草坪疏植）/ 乙（处方式庭园）/ 丙（建筑化庭园）。城主批复**「批准乙·处方式庭园（推荐）」**。
- **落位核对**：D5 九地块至此全部落定（一期 4 + 二期 2 + 三期 3）。北界 z=−10 与一期宗地**直接相接**——愈光楼的南花园就在前庭北缘，人从楼里出来直接踩进这片绿；南隔 12m 城市道路对 D6（nemotron-3-ultra 的 AI 创新谷）；东邻静息塔，西临 C5 尚空。**无围栏**，三面开敞。
- **未触发总图修订**：宗地、功能、期数、低伏地景定档均按总图第 3 期落位。

## 立意

**《把一整块地还给走进来的人》**。

一、二期是「被治疗的身体」；三期是**可以不带目的走进来的一片绿**。它不是「公园」，是一张**处方的平面图**——每一块地对应一种好起来的方式：

| 处方 | 场地 |
|---|---|
| 坐着 | 三级草坡静坐阶（每级 1.33m 进深 / 0.45m 高差，21 张木坐凳） |
| 走着 | 2.2m 宽环形康复步道（半轴 12.6×4.9m）+ 30 盏庭院灯环 |
| 闻着 | 6 道可识别的药草畦（各 2.5×1.15m，6 种叶色 + 木质铭牌） |
| 看着 | 9 株朴树阵（3×3，≤8.9m）+ 90 丛地被 |
| 吃着 | 中药茶座亭（石桌 + 8 只陶药罐的三层药柜架） |
| 练着 | 低强度康复器械区 6 组（太极揉推器 / 蹬力器 + 平衡板 / 漫步机 + 引体架） |
| 被雨冲着 | 雨水花园（下沉 0.9m bioswale，165 枚卵石 + 296 支芦苇 + 3 块踏步石 + 木栈道 + 石堰溢流） |

园心另有一座**「四时」铜药盘**——24 道放射铜条与一根晷针，把全园的处方讲成一句话：**同一个太阳，四种时令，坐着看它走完。**

## 方案比选（第 4 步）

| | 甲 · 全草坪疏植 | **乙 · 处方式庭园（获批）** | 丙 · 建筑化庭园 |
|---|---|---|---|
| 体量 | 大草坪 + 几株大树 | 全部构筑物 ≤5m，最高是 8.9m 的树 | 东端加一圈 5m 连廊串三亭 |
| 布局 | 无分区 | 七种处方各占一块地 | 亭群 + 连廊围合 |
| 细节策略 | 草皮、树、几条路 | 静坐阶 / 灯环 / 药草畦 / 雨水花园 / 器械 / 花境 / 铜药盘 | 连廊柱列、檐口、铺地 |
| 气质 | 公园广场，来了也不知道干什么 | 一张处方，逛一圈把七件事都做一遍 | 院子，有顶但失去开敞 |
| 问题 | 无主题，全城任何一个广场都能这么画 | 维护要求高（药草畦与雨水花园要人打理） | **违背总图「低伏地景」定档**；且 60×20m 的开敞被压成 20m 宽的院子 |

**结论：采乙案**（城主批复亦为乙案）。理由：甲在立意上出局；丙违背总图定档。乙的风险是养护——药草畦与雨水花园须由街区运营持续打理，已列入下方「待深化」。

## 渲染自评（第 8 步四件事）

工具：`npm run shot -- b-000030-yuguang-court --views corner,street,aerial --amb day,dusk,night --width 1280`（零浏览器软件光栅化，秒级）。

- **轮廓剪影**：全园最高 8.8m（7.6m 树阵 + 1.2m 树池），亭群 ≤5m，廊架 3.8m——严格守住总图「低伏地景」定档。放在静息塔（67.2m）脚边，是一整片能把 72m 压下来的绿。
- **比例尺度**：60×20m 的长条地被，环形步道半轴 12.6×4.9m 把长条切成「三个院子 + 一条环」；静坐阶三级共 1.35m 高差，是全园唯一的高度变化，正好把长条地形在北侧「切」出一道。
- **细节密度**：372 枚花头 + 296 支芦苇 + 165 枚卵石 + 276 丛药草叶簇 + 236 丛地被与绿篱 + 30 盏庭院灯；三角 162,318（护栏 11%）、mesh 2,505，高于 R11 底线 150,000。
- **材质层次**：草皮 / 深草坡 / 两种铺装 / 两级石材 / 浅木与深木 / 金属 / 玻璃 / 铜 / 六档绿 / 六种花色；黄昏与夜景下 30 盏庭院灯环是全园唯一的秩序感来源。
- **与一、二期的关系**：一期南花园（`cities/c1/buildings/b-000027`，院落称「内庭」）的南缘与本园前庭北缘直接相接，愈光楼的人从楼里出来踩进第一排椽下；静息塔的底从东侧落到本园的器械区与茶座亭之间——**一栋楼、一座塔、一片庭，D5 的九地块至此闭合**。

### 施工期踩坑记录

1. **健康咨询亭整体南移 1m**：初稿放在 (16.6, −6.2)，体量 6×4.4m 落到 z −8.4，屋面落到 −8.7，直接撞 R13 退线。庭园类建筑的通病——**亭子一旦贴着退线放，屋面挑檐就会越线**，需给屋面留 0.3m 余量。
2. **前庭朴树树冠越 R2**：初稿 crown 2.1 / spread 2.0 时树冠顶端到 z 12.06，超出宗地边界 1.5m（**R2 查的是所有几何，包括 site 件**）。树冠外扩量 ≈ `spread×1.3 + crown×0.6`，往边界放树时须按这个量反算。
3. **树高定档按「整株最高点」算，不是按 trunk 的 h**：`healingTree` 的树冠顶在 `y + h×0.52 + crown×0.6` 附近。首稿 h=8.9 名义合规、实际渲染 11.1m，被总图「树 ≤9m」定档超出 2m。**定档类约束要按渲染实测值校，不要按参数值自认合规。**

## 待深化（续建自评清单）

① **养护责任未落**：药草畦与雨水花园需要人持续打理（拔草、换季、清水），总图写了「周末向全城开放」但没写谁开。建议城主在街区运营层面指定承接方，或在 D5 总图补一条维护条款。② 药草畦的 6 种叶色目前靠色差区分，续建宜做可辨识的种植分区标牌与名牌（拉丁名 + 用途）。③ 南缘花境的 6 段花卉目前按色带排布，续建宜按花期排（春 / 夏 / 秋 / 冬四段），使全年都有花。④ 环形步道 2.2m 净宽对双向轮椅通行偏紧，续建宜在东半段扩到 3m。⑤ 园心铜药盘的晷针朝向未按真太阳时校准——城市尺度下不影响，但若城主在意可按 D5 的实际纬度与地块朝向重算。
