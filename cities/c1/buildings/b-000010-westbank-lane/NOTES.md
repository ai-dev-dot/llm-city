# 西岸里 Westbank Lane —— 设计文档（D4 街区三期，宗地 D4-08+09，40×20m）

## 立项

- **日期**：2026-09-27
- **总图依据**：`cities/c1/blockplans/D4.md` 第 3 期——D4-08+09「公园经济带——咖啡/书店/生活服务」，
  限高 12m，南界面与 E4 公园南岸步道衔接，东端（D4-09）临镜湖公园。
- **提案**（builder → 城主）：三期轻量立项——按总图第 3 期于 D4-08+09 建公园经济带，立意
  「南檐坡屋」：沿南岸连续轻外廊（坡玻璃雨棚檐下步廊）接通 E4 南岸步道；廊后三段业态——
  西段咖啡（双坡玻璃天窗）、中段书店（2 层平屋面 + 屋顶露台，街区南界面制高 12m）、
  东段生活服务（单坡木格栅棚）；北面对中央光庭全玻璃橱窗界面；东端临湖角玻璃亭与树阵广场。
  一拱（一期）二平（二期）三坡（三期），补全模都「消费与烟火」环的生活服务半径。
- **城主批复**：2026-09-27「开始三期」——**批准动工**。
- **未获城主同意前不动工**；本节即宪法第 12 条立项确认实录。

## 立意

续写街区母题「玻璃·橱窗·骑楼檐」的第三种檐：一期东拱廊、二期平梁骑楼，三期以**轻钢坡玻璃雨棚**
收束——公园边的檐更轻、更透。功能上补全街区服务半径：咖啡（晨跑补给，接 E4 晨练人群）、
书店（文化停留）、生活服务（洗衣/快递/药房，落地即住的烟火）；南檐下步廊是 E4 南岸步道的
西向延伸，「跑步的人沿岸向西、进檐下歇脚」。北面以整幅橱窗对中央光庭发光，与二期市集大厅
隔庭对望；入夜南廊串灯与竖招亮起，兑现街区性格「檐下可停、入夜有招牌灯」。

## 形制分项（局部原点 = 宗地中心，北 +z 对光庭，东 +x 临湖，南 -z 临 E4 南岸步道）

- **场地**：草皮满铺 40×20（顶 0.3m 地被豁免）；南沿岸步道带（z−9.3，接 E4 南岸步道）、
  北对光庭带（z+9.3）、东西接口带（x±19.3）错缝铺装；东角临湖树阵广场铺装（x18..20 环带）；
  行道树 12、路灯 10、坐凳 6、绿篱 4、石盆 4。
- **南外廊**（檐下步廊 z−7.9..−5.5）：方柱 0.45 @ 每 3.9m 共 10 根 + 柱脚柱头 + 通长梁
  y4.75..5.15；坡玻璃雨棚自北 y5.6 落南 y4.95（钢梁 2 道 + 玻璃板 + 纵横分格挺）；
  廊道铺装全宽；檐下吊球灯 9 盏 + 长椅 4；柱头竖向霓虹刀牌 3 块（三业态色）。
- **主体三段**（合并石实体，退线核 |x|≤18、|z|≤8 内，段间 0.3 阴影缝）：
  - 西段咖啡 x[−18,−6.6]，y0..6.6（通高 6.6）；
  - 中段书店 x[−6.3,6.3]，y0..6.6 + 2 层 y6.6..11.2，女儿墙至 **12.0**（总图档内）；
  - 东段服务 x[6.6,18]，y0..6.6 + 北条二层至 8.8；进深统一 z[−5.4,8]。
- **北立面**（对光庭主界面）：底层九开间橱窗（西/中/东各 3，退 z7.75 朝北，招牌带 +
  暖光衬板 + 展台）；中段 2 层密梃幕墙 y6.6..11.2（cols6、遮阳片、夜景暖窗）；西东段檐上
  女儿墙压顶收头；东山墙竖向发光招牌对湖。
- **南立面**（廊后）：九开间橱窗朝南（ry=π，对步道）；中段 2 层南向幕墙俯瞰南岸；
  西东段檐上露台栏杆。
- **屋面**：西段双坡玻璃天窗（脊 y9.4 E-W 走向，两坡落至 6.6 檐，椽 18 道/坡 + 横条 +
  脊盖）；中段屋顶露台 y11.2（铺装 + 栏杆 + 花池 + 伞桌 + 女儿墙环 + 机房百叶）；
  东段女儿墙 8.8 + 木格栅棚架（9 柱 + 梁 + 格栅条，棚下露台铺装 + 长椅）。
- **檐下坐憩**：南廊道长椅 3 + 柱间花池 + 吊球灯 9；东段棚下长椅 2；中段屋顶露台伞桌 2 组、
  机房矮箱（≤12m 收头）；橱窗为贴面式发光体系（玻璃自发光 + 招牌 + 上亮带做夜景景深）。
- **东端临湖角**：东山墙整幅幕墙（ry=π/2）+ 树阵 3 + 石盆 + 灯，铺装广场接镜湖南岸。
