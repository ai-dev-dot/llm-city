# b-000021 · 蓝图馆 Blueprint Hall（城市规划馆）

E5「原点街区」四期收官作——模都的城市规划馆，低层展馆，展示这座城市怎么从一块地长成一座城。

## 立项（宪法第 12/13 条确认实录）

- **2026-09-28 · 轻量门（四期）**：城主指令**「四期开工」**（2026-09-28 会话实录，紧随三期叠澜塔报验与 push 之后），即按 E5 总图四期执行：于宗地 E5-07（南排西，1×1，20×20m）建**城市规划馆「蓝图馆」**——低层展馆，展示模都建设史（呼应城市叙事），~20m 低层档位。
- **总图引用**：`cities/c1/blockplans/E5.md`「原点街区 Origin Quarter」四期。建设时序：一期 原点塔（b-000001）→ 二期 光环广场（b-000019）→ 三期 叠澜塔（b-000020）→ **四期 蓝图馆（本建筑，街区叙事收口）**。
- **街区关系**：北邻原点塔宗地（E5-04 塔基座西南），东邻光环广场（E5-08 西半）——主入口朝东迎接自广场来的人流，北面设次入口；总图天际线策略「规划馆 ~20m 低层压住西南」——本馆以水平舒展的低体量收住双塔街区的西南角。

## 立意

**「蓝图」**：城市在成为城市之前，是一张图纸。蓝图馆是模都的记忆容器——白盒体量像一张摊开的晒图纸，蓝图青（cyanotype）玻璃带是图纸的线条语言；中央通高中庭里放着**微缩模都沙盘**：九宫格街区、已建的六个街区各有微缩剪影，E5 三件套（原点塔/光环广场/叠澜塔）逐件可辨，**沙盘的西南角还有一座小小的蓝图馆**——馆里看城，城里也有馆。中庭顶是一圈**发光圆环天窗**——E5 圆环母题的最后一环：原点的光庭（地面）→ 塔冠的环（空中）→ 广场的水环（地面）→ 澜环（塔身）→ **蓝图馆的天窗环（收口）**——白天采光、入夜微光，为街区叙事画上句点。

**形制分项**：

- **主体**：15.6×15.6×10m 两层白盒（浅暖白石板），层间银带分隔出「悬浮二层」；四向立面：一层横向展窗带（蓝图青玻璃+银框）+ 二层竖条窗阵 + **图框勾边线**（立面四边细银线，像图框）+ 角部小青牌（图号牌）。
- **中庭阁**：8×8 圆角方玻璃阁从屋面升起 6m（总高 ~16m ≤ 总图 ~20m 档），双层通高；顶为 **r3 发光圆环天窗**（白天白光/夜暖金微光——E5 母题收口环）+ 环内十字采光梁。
- **沙盘**（中庭内）：**E5 街区 1:11 微缩总图沙盘**——6×6 台座、3×3 地块网（格 1.6）+ 道路缝 + 图纸细格，四件套逐件可辨：微缩原点塔（三段错动收分+竖棱+腰线盘+金环冠+光庭微光点）、微缩光环广场（同心五环+小水环+放射刻度+16 柱廊点）、微缩叠澜塔（澜环六道+悬盘+盘缘微金环+电梯核）、**微缩蓝图馆（西南角，四向微窗+微天窗环——递归彩蛋：馆里看城，城里也有馆）**；另有微树阵 20、微车流点 12、台前发光铭牌、台座展柜灯带双环、参观围栏；二层两跑楼梯上环廊俯瞰。
- **二层俯瞰环廊**：沿中庭四周悬挑 1.2m 内廊 + 栏杆——现实规划馆经典视角：从二层俯瞰整座微缩模都。
- **入口**：东主入口（双柱门斗+贴墙青金梁雨棚+双扇玻璃门）迎光环广场人流；北次入口。
- **场地**：东前庭**蓝图坐标网格铺装**（1.5m 网格缝+青色轴线+同心圆欢迎地花）+ 四角图纸角标墩；南/西/北草皮树阵（8 树）+ 步道；modernLamp×2 + bollard×8。
- **夜景**：中庭内透亮（沙盘展灯）→ 天窗环微光 → 立面窗带内透青白 → 场地灯——安静的知识灯态，与酒店的满房暖光、塔的加班灯三分街区夜色。
