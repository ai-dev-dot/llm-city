### 立项执行修正（首次施工内完成，据实留痕）

批复的乙案原文是「8 层通高光井 + 逐层环形挑台 + 顶部漏光柱」的光井独院（环形本体围合 16×16m 露天中庭）。首轮渲染自评发现致命问题：**40×40m 宗地上四面围合的院子，从 D4 主街、F5/C5 各机位完全看不见**——`shot` 的街面与 45° 角视图只拍到一块 34×30m 的实心体量，立意不可见，等于把全城最核心的一笔预算盖在屋里。故作**执行修正**（非推翻立意，母题与总图条目均未变）：

| | 原乙案（不可见） | 落成「一塔一庭」（可见） |
|---|---|---|
| 光井位置 | 环形本体围出的**院子里的一个洞** | **塔内中庭**（x 8..16 / z ±6，8 层通高 + 逐层挑台 + 顶部采光顶） |
| 光如何被看见 | 只能站在院里抬头 | 透过庭院东壁 **31.2m 通高玻璃采光墙**对庭敞开；从 D4 街面与西面均能读出树与光 |
| 母题兑现 | 庭（光井）藏于体内 | **愈**＝塔与两翼的功能分置；**光**＝贯穿八层的采光顶与发光环梁；**庭**＝26×16m 露天愈光庭 |

保留的部分：8 层通高、逐层挑台、顶部漏光柱与采光顶全部落成，只是把「井」从院里搬进塔里，让它成为庭院的**背景光源**而不是屋顶的一个洞。

## 立意

**《一条会呼吸的处方》**。

模都已给了城市很多东西：一座 211m 的原点塔告诉人「你可以爬多高」，一千扇窗告诉人「这里有家」，一条灯花市集街告诉人「这里有人间」。但全城没有一栋建筑回答「你怎么了？」。愈光楼回答的是这个问题——而它的回答方式是**空间，不是招牌**。

病人从 D4 烟火街的市集走过来，穿过 5.4m 高的木色暖檐门廊，抬头看见的不是医院的标识，而是一座 **26×16m 的露天愈光庭**：庭东壁是一整面 31.2m 高的通高玻璃采光墙，墙后是八层通高的中庭、逐层挑出 1.4m 的呼吸阳台、吊挂着垂到下一层的绿植，墙脚是一池浅水，水上长着一株 16m 的银杏。抬头看光不是从窗户进来的，是从**一整面墙**进来的。

立面三段深度即三段处方：
1. **底层架空柱廊**（5.4m）——把候诊前庭让给人行道，医院不设高墙门禁，D4 街的人可以一直走进大厅；后勤段收在柱廊之后，公共与私密的边界靠一排玻璃而不是一道门。
2. **薄荷绿实体层间带 + 连续玻璃带 + 浅暖灰竖向遮阳鳍**——每层 0.85m 实体带定住水平基线，玻璃带是病人的窗，竖鳍（约 2.2m 一道、出挑 0.42m）替病房挡住低角度日晒与视线。鳍有节奏地重复，像呼吸：一进一退，光被筛过一遍再进屋。
3. **三层低翼屋顶花园**——18.3m 与 14.0m 的翼顶是可用的绿：种植池带、观景廊架、候诊露台。本城所有塔楼里唯一把「屋顶」给出去而不是收掉的。

风格是**现代医疗 + 疗愈花园**：白预制板、薄荷绿层间带、木色暖檐、清水混凝土、浅暖灰遮阳鳍、层层退台、800 枚立体叶簇的绿墙。与 E5 琥珀金镜、E6 石拱、E7 铁艺、F5 红砖、G5 银蓝科技、E3 白色博览明确区分——**别人用形说话，医枢用光与绿说话**。

## 方案比选（第 4 步）

同一宗地（D5-01+02+04+05，40×40m），三种形态差异明显的方案：

| | 甲 · 内庭独院 | **乙 · 光井独院（获批）** | 丙 · 双塔门架 |
|---|---|---|---|
| 体量 | 四翼合围露天方院 22×22m | 环形本体围 16×16m 通高光井（8 层） | 两座 30m 塔夹一条 60m 长空廊 |
| 立面 | 白板 + 常规方窗 | 白预制板 + 水平遮阳鳍带 + 逐层退台 | 双塔玻璃幕墙 + 廊顶钢桁架 |
| 细节策略 | 院墙爬藤、连廊、坐凳 | 鳍带、环廊挑台、吊挂绿植、采光顶钢肋、绿墙 | 桁架节点、幕墙梃、塔冠设备层 |
| 空间气质 | 亲切、低伏，传统医院四方院 | 竖向贯通、仪式感强，光井即公共厅堂 | 剪影最猛，与 E5 原点塔对撞 |
| 问题 | 竖向无仪式，病人抬头只有天 | **院子从街面不可见（首轮渲染实测）** | 体量分裂、庭院破碎，公共空间无处安放 |

**结论：采乙案并作上述执行修正**（城主批复亦为乙案）。理由：模都缺的不是又一座有辨识度的塔，而是一个「进去之后会安静下来」的内核。落成方案把乙案的八层光井从「院里的洞」改成「塔里的竖缝」，让它成为庭院的背景光源——建筑第一次把「等」变成了「看」。

## 渲染自评（第 8 步四件事）

工具：`npm run shot -- b-000027-yuguang-clinic --views corner,street,left,aerial --amb day,dusk,night --width 1280`（零浏览器软件光栅化，秒级）。

- **轮廓剪影**：初稿为 34×30m 实心方盒子（渲染实测：光井不可见）；现为「一塔一庭」，31.2m 塔贴东缘 + 18.3/14.0m 两翼压低，西侧让出 26×16m 露天庭——主从清楚，与 E5 原点塔（211m 金镜）、F5 报课钟塔（38m 书山）、G5 求索塔（95m 螺旋）三种既有剪影均不撞。
- **比例尺度**：层高 4.3m、檐口线脚 0.52m、遮阳鳍 0.42m 出挑，与 31m 总高匹配；庭院 26×16m 对 31.2m 照壁是约 2:1 的竖向比，抬头不至于空。
- **细节密度**：40 面幕墙 + 170 片遮阳鳍 + 88 根外露柱 + 三层屋顶花园 + 800 叶簇绿墙；三角 234,436（护栏 12%）、mesh 4,988，远高于 R11 底线。
- **材质层次**：白预制板 / 薄荷绿 / 木色暖檐 / 清水混凝土 / 玻璃 / 浅暖灰鳍 / 三档绿，七层可辨；夜渲时玻璃带与发光环梁、庭院光柱、门廊灯串成灯点序列。
- **下一轮待深化**：① 中庭 12 道药草畦的种植识别度偏弱，宜做成可辨的药草分区；② 门诊翼与康复翼的朝庭立面在体量上略平，宜加深凹阳台或加雨篷；③ 庭院地面铺装在俯视下略显空，宜加树阵与水景层次。

> 迭代策略：体量与光井 → 立面鳍带与窗洞 → 绿化与场地材质，一轮专攻一个维度；在建态可多轮续建，每轮跑 `inspect` + `shot` 对照本节自评。续建沿本立项免重复报批；若要推翻母题或改宗地，须重新走总图门。
