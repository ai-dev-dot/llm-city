## 立意

**《住进来的病人夜里怎么睡》**。

一期愈光楼解决的是「你怎么了」——进门、抬头、一池水一棵树。塔楼的命题不一样：**不是更高，是让病房有朝向、有树、有天**。

所以本栋把总图里那句「逐层朝庭露台」当真话做：每四层退一道 **6m 深的西向呼吸廊**，净高 3.1m、纵长 36m。病人推着轮椅推开病房门就进到廊里——头顶是楼板，脚下 36m 外是一期愈光庭的银杏，东侧转身是 40m 外的 D4 烟火街。四道廊分别在 **16.8 / 31.2 / 45.6 / 60.0m**，等距 14.4m，像四次深呼吸。

立面两面性格：
- **东立面（一整排 22 开间通长病房窗 + 16 道竖向遮阳鳍）**——隔 12m 城市道路正对 E5 原点塔。模都已给了城市 211m 的高度，这 40m 长的一排窗是本街区唯一能天天对着那道天际线躺着的地方。
- **西立面（L2–L4 是一整面 36m × 9.6m 的实体绿墙，800 枚立体叶簇）**——从一期愈光庭望过来：先是 31m 高的愈光楼通高玻璃照壁，再是这面从 6m 升到 16m 的绿墙，然后四道空中庭园一路上到 67m。愈光楼的院子因此有了三层纵深，而不是一面挡墙。

退台层（L5 / L9 / L13 / L17）整体西退 6m，剩 10m 进深的双走廊病房，退台层自己的西面是落地玻璃——对着自己的空中庭园。檐口 67.2m，塔冠 4.8m 至 72.0m：停机坪（9m 圆盘 + H 标 + 发光环 + 12 片安全网）、设备层、桅杆与航空障碍灯、护士休息绿带。

## 方案比选（第 4 步）

| | 甲 · 板式通长 | **乙 · 退台呼吸（获批）** | 丙 · 双塔夹院 |
|---|---|---|---|
| 体量 | 20×40 满铺板楼，18 层不断开 | 每 4 层退一道 6m 深呼吸廊（L5/9/13/17 退台） | 塔身劈成东西两片夹 6m 缝 |
| 立面 | 东面通长病房窗 | 东面通长病房窗 + 西面绿墙 + 四道空中庭园 | 东西两面各 7m 宽窗 |
| 细节策略 | 幕墙 + 遮阳鳍 | 幕墙 + 鳍 + 退台廊柱/栏板/种植池/木梁架 + 塔冠停机坪 | 中庭通高玻璃 + 桥 |
| 病房体验 | 无户外，病房只能看对面墙 | 每四层一次 6m 深有顶户外 | 每侧仅 7m 面宽，双走廊不成立 |
| 问题 | 「住进来的人夜里怎么睡」无解 | 退台层仅 10m 进深，双走廊可行但紧凑 | 剪影分裂，结构与病房尺度皆不成立 |

**结论：采乙案**（城主批复亦为乙案）。理由：甲在立意上就出局；丙在 20m 宽度上无法成立双走廊病房。乙把「露台」从装饰变成处方，且不额外占地。

## 渲染自评（第 8 步四件事）

工具：`npm run shot -- b-000029-jingxi-tower --views corner,street,left --amb day,dusk,night --width 1280`（零浏览器软件光栅化，秒级）。

- **轮廓剪影**：20×40m 板式塔，67.2m 檐口 + 4.8m 塔冠，西立面四道退台空中庭园等距 14.4m 上行——从任何机位都能一眼数出「四道」，这是本栋的剪影签名。街区制高点，低于对街叠澜塔 ~116m 与原点塔 ~211m，恪守「中心高四周低」。
- **比例尺度**：层高 3.6m、门厅 6m、退台深 6m、退台廊净高 3.1m。20m 宽的板上退 6m 后净宽 9m，双走廊病房成立。
- **细节密度**：约 693 片遮阳鳍 + 102 根外露柱 + 810 枚绿墙叶簇 + 4 道庭园廊（24 道种植池 / 168 丛灌木 / 12 株小树）+ 塔冠全套；三角 159,140（护栏 16%）、mesh 5,697，远高于 R11 底线 100,000。
- **材质层次**：白预制板 / 薄荷绿层间带 / 木色暖檐 / 浅暖灰鳍 / 木色深鳍 / 玻璃 / 五档绿，七层可辨；西立面自下而上「实体绿墙 → 玻璃病房 → 四道庭园廊 → 塔冠」四段层次，是全城唯一一栋把绿放在塔基而不是屋顶的塔。
- **与一期的关系**：一期住院翼 31.2m 止于宗地西界，本栋留 5m 缝（2m 退线林带 + 3m 一期余量）后起 67.2m——从愈光庭望东是「通高玻璃照壁 → 31m 绿墙 → 四道空中庭园」，三层纵深成立。

### 施工期踩坑记录（供后续 agent 参考）

1. **立面出挑必须计入 R13 退线**：初稿把塔身线画在 x ±8 / z ±18，随后又挂遮阳鳍（0.4m）、檐口线脚（0.48m）、深窗洞窗台（0.46m），全部从这条线往外长 → 4,336 个构件越线。**修法：把 BX/BZ 定义为「玻璃面」位置，让最外出挑恰好落在退线内**（BX=7.5 / BZ=17.5）。这是 R13 最容易踩的坑，比体量算错更隐蔽。
2. **同一面不要同时挂玻璃与绿墙**：初稿西立面 L2–L4 既加幕墙又加绿墙，几何在同一平面上打架。**改为该三层用实体绿墙替代玻璃**，逻辑才成立——「塔基先是一面绿」本来就是立意。
3. **退台廊端头栏板的转轴**：`railing` 沿局部 X 展开且以其 position 为中心，西向 36m 侧边要 `rotY=π/2`，但南北 6m 端头必须保持 `rotY=0`；端头也转 90° 会让栏板跑到 z ±20.9 直接撞 R2。
4. **探针定位**：工作间 `probe.mjs` 复刻 worker 的 R13 判定逐件打印越界构件（几何类型/世界包围盒/超出量），把上面第 1、2 条从「4336 个红灯」压到 2 个、再到 0。建议并入官方工具。
