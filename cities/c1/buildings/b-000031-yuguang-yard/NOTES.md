# 愈光庭养护所 · 模都第一栋市政建筑

- **建筑 id**：b-000031（`buildings/b-000031-yuguang-yard/index.ts`）
- **登记**：`builder = { model: "official", model_id: "official", agent: "official（space-bunny 代拟）" }`
- **宗地**：C5-06+09（1×2 两排，**20×40m**，C5 东列南段，锚点 C5-06）
- **豁免**：official 市政配套——豁免街区主权（R15）、品质下限（R11）、设计文档（R12）、退线（R13）；R1/R2/R3/R4/R5/R6/R8/R9/R10/R14 全部适用
- **施工归属**：**城主 2026-09-30 裁定「建养护所，让市政可见」并授权代拟代码**。official 建筑按宪法第 12 条为城主自营、豁免立项门，故本栋不另报立项。代码由 space-bunny 撰写，git 历史可溯。

## 为什么有这一栋楼

起点是愈光庭 NOTES 里那句「养护责任未落」。核实后发现：**模都渲染是纯静态的**——`web/src/city/ambience.ts` 内无任何时间维度（无 `Date`、无 `elapsed`、无季节），`main.ts` 的 `setAnimationLoop` 只驱动相机。所以「三年后没人管」在模都不是一个可以被渲染出来的状态。

于是养护只有两种存在形式：**一栋看得见的楼**，或**一段读得到的文字**。本栋是第一种的载体——它同时补上全城更早就有的缺口：F5 悬铃木场「周末向 F4/F6 社区开放」、E3 文化广场「无围墙开放园区」、D4 中央光庭「留白开放」，四处都承诺了开放而无一家指定谁开门。**模都此前 0 栋官方建筑**（原界碑 b-000002 已于城市清零时拆除），市政没有载体，「谁维护」只能是空话。

## 立意

**《一间看得见的市政》**。

养护所不该是后院。它是一间**小工坊**：门朝东对着愈光庭，堆肥台和苗圃摆在院外让人看见，工具挂在墙上。城市里其他地方的绿都是干净的，**只有这里承认绿会消耗**——堆肥槽里躺着分层的落叶、草屑与熟肥，是全城唯一一处「脏」的市政构筑物。

选址 C5 东列南段：与愈光庭（D5-07+08+09）**共享 20m 前缘、中隔 12m 城市道路**，推门出来过条街就是庭园。

**刻意压低：除水塔顶灯 10.2m 外全部 ≤8.4m，低于愈光庭的树阵 8.8m。维护者不该比被照顾的树高。**

official 豁免 R11 底线，故不按宗地地块数追面数；本栋的取舍是**把钱花在能证明「这是养护所」而不是「这是另一栋房子」的细节上**：

| 苗圃 224 株小苗 + 竹架 | 17,900 | 养护所的产出物：这些苗是给愈光庭补种用的，是全城唯一的「绿的生产线」 |

## 施工踩坑（五条，都是校验器看不见或不管的）

① **宗地尺寸想当然**。C5-06+09 我按 20×30 画了（以为 06/09 是同一列两格），实际 **06 在中排、09 在南排，是 1×2 两排 20×40m**。是 R2 那句「宗地 20×40m」把它喊出来的——但因为 official 豁免 R13，越界没人拦，北端 10m 白空也没人拦。**教训：宗地尺寸以 `parcelDims` 为准，别按 lot 编号想；official 豁免的规则要自己补测。**

② **ExtrudeGeometry 的 depth 会被旋转搬到 Y 轴**。屋面板剖面画在局部 XY、`depth` 沿 +Z 是进深，我顺手加了 `rotation.x = -π/2` ——结果 12.5m 的进深被立起来，屋面上凭空插了一块 12.5m 高的板。R3 报「高度 20.9m」正好等于 `8.4 + 12.5`，对数才看出来。**剖面在 XY、depth 已是 Z 的话根本不需要旋转。**

③ **`lib/blocks` 的 `neonSign` / `latticePanel`：`w` 走 X，面法线朝 ±Z，`y` 是底不是中心**。我当它们沿 Z 摆，两处牌匾直接超出退线 1.3m（R13 豁免，inspect 报「官方建筑豁免退线」，数字被丢掉）。**要牌面朝东就 `rotation.y = Math.PI/2`。**

④ **公示牌把堆肥台挡死了**。两者都在东缘，公示牌 2.8m 高、堆肥台 1.4m 高，同 z 段时高者把低者遮得一点不剩——而「让人看见堆肥」正是本栋的立意。更糟的是发光刻线贴在局部 `x = -0.5`，落在 0.9m 墙厚内侧，**周期表等于压根没上墙**。改：牌移到 z=−8 单独占一段，刻线格与标题牌一律贴东面 `x = +0.5`。东缘自南向北读作「堆肥台 → 大门 → 亮着的周期表 → 值班室满窗」，四件事各占一段互不遮挡。

⑤ **铁艺门给了实心底板**。渲图里两扇门读成两块灰板。加了 `box(0.08, 2.6, 1.8)` 当门扇本体，8 根竖棂全被盖住。删掉底板只留棂与横档，门才是门。

## 自建工具与自测

- **R14 红灯（ instructive）**：本栋登记为 `official`，而 R14 只认 `lib/*` 与 `blocks/<你的 model_id>/`——**official 建筑不能 import 任何模型的私建积木**。种植畦与行道树两件就地写在 `index.ts` 里（`bed()` / `tree()`），市政建筑自包含，天经地义。反过来 `blocks/official/lantern.ts`（城主投放的须弥座石灯示范件）是可以引的，本栋 7 盏庭园灯就换成了它。
- **R13 自测**：`node_modules/.cache/llm-city/workshop/space-bunny/probe31.mjs`（工作间，不入库）。因为 official 豁免 R13，inspect 只回一句「豁免」就把 `setback` 数字丢了，而 worker 其实一直在算。探针复刻同一套判定（`Box3.setFromObject(m, true)` + 祖先链 site 豁免 + 地被/小件/薄板三类）——**当前越界构件 0**，退线由 layout 常量自洽保证，不靠校验器兜底。

## 已知取舍与后续

① **管养周期表刻在墙上而不是只在文档里**——这是本栋存在的全部理由；若日后周期变更，需由城主改 `index.ts` 重跑（不涉他模型资产）。② **C5 不因此成为 space-bunny 的街区**：登记为 official，R15 豁免街区主权，C5 的归属权不受影响；C5 目前无 `blockplans/C5.md`，若日后有别的模型进驻，走他们自己的总图门。③ 官方建筑若增多，可考虑在 `plan.json` 之外另立一份市政设施清单——目前 1 栋，尚不需要。④ **E3/F5/D4 三处同样「承诺开放而无管养方」的缺口仍未补**：本栋只服务 D5 愈光庭，替不了别家街区署名；是否立一条 CITY.md「公共空间管养」通则，仍待城主裁决。
