# b-000020 · 叠澜塔 Ripple Hotel（天际酒店）

E5「原点街区」三期天际酒店塔——与原点塔构成东西双塔的从体量，街区天际线的第二声部。

## 立项（宪法第 12/13 条确认实录）

- **2026-09-28 · 轻量门（三期）**：城主指令**「开始三期」**（2026-09-28 会话实录，紧随二期光环广场报验与 push 之后），即按 E5 总图三期执行：于宗地 E5-03+06（东列北+中，1×2 竖宗地，20×40m）建**天际酒店塔**——从体量，与主塔构成东西双塔，~110m 档位。
- **总图引用**：`cities/c1/blockplans/E5.md`「原点街区 Origin Quarter」三期。建设时序：一期 原点塔（b-000001）→ 二期 南广场（b-000019）→ **三期 酒店塔（本建筑）** → 四期 蓝图馆。
- **双塔与街区关系**：宗地贴原点塔宗地东缘（全局 x=10 共界）——酒店塔与主塔东西并立，主塔 211m 居西北为全城第一制高点、酒店主体 ~110m 居东为从体量，从南面城市干道与二期光环广场看为「左主右从」的双塔层次；塔身南面俯瞰光环广场，顶层 sky lounge 西望主塔塔冠金环、南望全城。

## 立意

**「涟漪升空」**：二期光环广场把原点放回地面荡成涟漪，三期把涟漪竖起来送上天空——塔身每层客房的弧形阳台是一圈圈「澜环」，随高度**呼吸起伏**（竖向波长约 11 层）：波谷贴身、波峰化为大露台层；塔顶一朵最大的澜——悬挑胶囊盘 sky lounge，外缘一圈**无边泳池**与金色发光环。地面的水环（广场镜水）在 110m 处再现：**涟漪从广场荡到天上**。东北弧面半嵌的通高观光电梯核（三条铜金竖光带）是夜晚的竖琴——住客登塔即「溯澜而上」。

酒店性格与主塔（写字楼冷银蓝、稀疏加班灯）区分：暖白阳台节奏+**夜里六成客房透暖光**的「满房」灯态+基座弧形橱窗餐饮街。

**形制分项**：

- **平面**：胶囊形（半宽 7m 东西 × 半长 10m 南北），塔身中心居宗地中心；R13 本体线内（澜环最宽 7.7、悬盘 7.9 ≤ 8）。
- **竖向**：基座 7.5m（胶囊 7.5×10.5，弧形橱窗餐饮街）→ 塔身 33 层 ×3.1m（7.5–109.8m，主体 ~110m 贴总图档位）→ sky lounge 悬盘（109.8–114.5m）→ 电梯核玻璃厅+顶帽（至 ~116.2m）。
- **澜环体系**：每层楼面线处胶囊环形阳台板（extrude 环带，呼吸量 e(k)=0.18+0.52·(1+sin)/2，波长 11 层）+ 栏杆竖杆阵（每 0.78m）+ 扶手细环 + 层间檐线；波峰层（e>0.6）化作大露台（绿植池+灌木+躺椅）。
- **竖向鳍**：东西直段各 4 根+南北端各 1 根通高银鳍（波谷露出波峰没入——澜间脊线）。
- **sky lounge**：倒锥盘+主盘（胶囊 7.9×13 悬挑）+ 外缘无边泳池环 + 金色发光缘环 + 悬挑斜肋 + 盘上吧台弧墙/绿植/躺椅。
- **观光电梯核**：东北弧面半嵌圆筒 r2.1 通高，玻璃+三条铜金竖光带，底接大堂电梯厅、顶入 sky lounge。
- **大堂**：南端两层通高玻璃盒（15.6×8×7.5）+ 南主入口金色弧雨棚+双柱门斗+檐下柱廊 6 柱；门前涟漪弧铺装三条（被大堂「岸」裁断——同二期裁岸语言）+ 落客带 + 旗阵 5。
- **北后勤院**：铺装+围篱+冷却塔阵 3+卸货棚。
- **场地**：东西退线环带草皮+树列各 4、北院树 2、南旗阵侧树 2；modernLamp×6+bollard×8。
- **夜景**：核心暖底光（满房感）→ 六成客房层随机暖白灯条 → 澜环檐线微光 → 盘缘金环+泳池水光 → 电梯核铜金竖带 → 大堂全透亮。

## 施工记录

- **一轮（2026-09-28，zcode / glm-5.3）**：首建 + 自评迭代。工程要点：`pushGeo` 兼容非索引几何（ExtrudeGeometry 无 index，顶点序即三角序）；胶囊轮廓弧长参数化 `capPoint` 统一驱动竖杆/灯条/橱窗筋/悬挑肋的切向摆放。inspect 排障三处（探针 `workshop/glm-5.3/probe-*.mjs` 定位）：①入口弧雨棚 r4.3 从门线外挑越 R2/R13（门线距南界仅 2.5m、距 R13 退线仅 0.7m——任何外挑雨棚必越界）→ 改**贴墙金梁门斗**（横梁+短臂+双柱，界内）；②RingGeometry 方位角约定实测纠偏（workshop 探针：rotateX(-π/2) 后 φw=thetaStart 直接映射）——门前涟漪弧按南半圆 [-π,0] 重做（门前窄带仅 2.3m 深，三圈小涟漪 r0.9/1.5/2.15）；③**sink 合并陷阱**：露台家具/北院围篱合进大 sink 后整体 bbox 丧失小件/薄板豁免——家具 sink 挂 `userData.site`、围篱独立薄板 sink。悬挑肋径向倍率过大（1.55→1.045）收回 R13 线内。shot 视觉自评一轮：「图钉」构图成立/澜环呼吸节奏可读（3 个波长）/夜景四项过（悬盘金环焦点/满房灯态/电梯核铜金竖光带/无过曝）；对症补**束腰过渡环** 3 圈（塔身→悬盘的收束句读，悬盘「直接相连感」消除）。R1–R15 全绿：**306,480 三角 / 240 mesh / 高 116.2m（主体 109.8 ≈ 总图 ~110m 档）**。token 统计不可得记 null（宪法第 6 条如实）。
