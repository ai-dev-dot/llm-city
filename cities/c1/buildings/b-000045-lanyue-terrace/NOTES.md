## 立意

《手中的月》。主塔的月在 108m 塔尖、揽月阁的月在云阶上、月庭的月在穹顶——都是**天上的月**，仰头才见；揽月台给市民一枚可以走近、围坐、倒映的月——**手中的月**。顶奢街区最容易做成「富人的围墙花园」，本栋是全街区唯一的纯公共开放空间：无围墙、无门禁、四条月相步道从四个方向把人放进来——顶级街区的收官不是更贵的门牌，是把月光还给市民。

## 设计

### 方案比选（三案）

- **案 A 三重月落花园（选定）**：月相环广场（脚下）→ 望月坛（手中）→ 月牙池（水中），三重「月落」把街区母题从天上收到地面；南观星草坡、东疏林留呼吸。叙事完成度最高，「市民的月」成立。
- **案 B 纯大草坪 + 孤植树**（伦敦广场式）：呼吸感最强但母题缺席——街区最后一格若无「月」字收口，一族三月缺地面章。
- **案 C 几何迷宫园**（法式刺绣花坛）：华贵但封闭感强，与「无围墙、留呼吸」的总图定位相悖。

结论：案 A。

### 形制分项（三重月落 + 四向呼吸）

- **月相环广场**（中央 r6.5）：环形铺装 + 8 道径向铜条（指月八向）+ 8 块月相石板环列（朔弦望晦有序）+ 内盘小熊座七星铜点阵（星点 + 连线，仰头望月前先认脚下的星）。
- **望月坛**（环心，坛顶 ~5.2m ≤ 6m 档）：三层圆坛（r3.2/2.5/1.8，坛沿铜环）+ 坛身 8 块月牙浮雕板 + 石柱托小月牙（r0.9 微光，市民的月）+ 坛周八边形密柱环栏（8 段）+ 环形长凳 3 组朝坛。
- **月牙静水池**（北，r2.3 平放月牙形，尖角朝东）：池子本身就是月牙——「月落揽月台」；池心月珠一点光 + 池畔石凳石盆。
- **观星草坡**（南，两层石砌台地 1.1/2.2m）：石砌缝台地 + 双侧 6 级石阶 + 坡顶揽月石台（斜面观星躺石 ×2，仰观天象）+ 北缘栏杆 + 台地树。
- **东疏林草坪**（5 株散植 + 东缘长凳看 G3 方向，留呼吸）；西缘列树 + 入口石盆（接一期前庭）；西北绿篱。
- **场地**：草皮满铺，四边月相步道（12 块石板续街区序列）+ 四角路灯。

### 迭代实录（shot 自评 → 修正）

- 两轮 R11 追密度：环栏柱距 0.42→0.30、坛身浮雕 8→16、圆坛 32→48 段、铆钉环/路缘石/星图铜盘/汀步补足 → 55.2k 达标。
- 顶视验证：月牙池平放月形、环广场同心圆 + 八向铜条、星图铜盘——「三重月落」平面构成立。

### 材质与夜景

草皮 + 月光石台地 + 铜条点星。夜景克制（开放空间不抢建筑的光）：望月坛月牙微光 + 池心月珠 + 四角路灯——三重月落之三，在夜里是**脚下与手边的一点亮**，与三栋建筑的檐口暖金遥相呼应。
