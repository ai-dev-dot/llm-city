# 展览中心 · E3 博览中心二期 — 设计文档

> 建筑 ID：b-000032

## 立项

- 按街区总图 `cities/c1/blockplans/E3.md` **二期**于宗地 **E3-04+05+06**（中排 1×3，60×20m）落建「展览中心」，立意不偏离总图，随总图门一并确认。

## 立意

展览中心是博览中心二期，母题**展**——流动屋面（参数化波浪板）+ 展厅序列 + 中央大厅 + 屋顶采光带。中央主楼 ~40m 居街区唯一竖向标记，屋面对原点塔，兑现「中轴对原点」。

对景逻辑：
1. **中轴对原点**——展览中心中轴西望 E5 原点塔（~211m）：展览中心 ~40m 甘居中轴第二高，与求索塔 ~95m 同档，恪守「中心高四周低」。
2. **北对体育馆**——北缘隔 12m 城市道路正对一期体育馆（b-000028）：从体育馆出来过街即展览中心北广场，「体育在中心，博览在核心」。
3. **南对广场**——南缘隔 12m 城市道路正对三期文化广场（E3-07+08+09）：从文化广场出来过街即展览中心南广场，「文化在广场，博览在中心」。

## 形制分项

- **场地（60×20 满铺至红线）**：草皮 60×20 + 西入口广场 16×12 铺装 + 入口台阶六级 + 旗杆 2 + 灯柱 8 + 长椅 6 + 树阵 24 株。
- **基座（56×16×1.5m）**：清水混凝土台基，退线 2m 环带全部做场地。
- **裙房（56×16×15m）**：玻璃幕墙 + 白色金属框架，四面密梃。
- **中央主楼（30×12×40m）**：玻璃幕墙 + 白色金属框架，顶部流动屋面。
- **流动屋面**：参数化波浪板——沿 X 轴方向，Y = A * sin(k * x + phase)，A=2.5m，k=0.35，phase=0。
- **屋顶采光带**：中央主楼顶部环形天窗（TorusGeometry 压扁）。
- **西入口**：柱廊 8 根 + 台阶六级 + 雨棚 16×0.5×6m。
- **材质**：白色金属屋面 #E8E6E1（metal 0.4 / rough 0.35）、玻璃幕墙 #9EC5DD（metal 0.5 / rough 0.15 / emissive #C4DFF0 0.25）、清水混凝土 #C4C1BA、深色 #3E3C3A、草皮 #7B8A6F、铺装 #A8A5A0。所有随机（树冠微偏）走 `ctx.rng()`，确定性达成。
