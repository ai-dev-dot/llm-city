## 立意

高端住宅塔楼。名「望湖」：西向高区越过临湖低院，可尽揽镜湖水面与西南方向的原点塔；塔楼居宗地北端（F4-03），实际 96m（总图 ~90m 制高点档位，顶部灯阁使总高略上浮），与 E5 西北象限 200m 原点塔**斜向环抱镜湖**——两塔一东北、一西南，共映于湖东南水域。塔楼恪守「中心高四周低」，绝不压原点塔；裙房 2 层临街商业，给街区以街市温度。

**结论**：取 **B**，并吸收 C 的望湖诉求——塔楼**西、北立面为尊**做满飘窗灯幕墙，**西—北转角由通高结构角柱收束、两面玻璃贯通至角**，高区透过满布窗玻璃获得近 270° 观景面，把镜湖与原点塔尽收。

## 形制分项

- **场地（宗地 20×40m，全域场地设计）**：基底铺装满铺至红线；北/东/南/西四圈 2m 人行道环带；北街、东街及西环带布置行道树与路灯；西环带裙房段设咖啡外摆。
- **塔楼（北端：大堂 + 22 标准层 + 灯阁，总高 96m）**：
  - 底部 **6m 通高入户大堂**：深色反光落地玻璃围合（南/东/西三面 + 北向两侧），北向中央暖光大门 + 金属雨棚 + 台阶，大堂内顶暖光板——夜间整座大堂透出暖光（温暖光盒）；
  - 标准层（y6–72，22 层 ×3m）：楼板 + 四角结构角柱 + 四面**飘窗灯幕墙**（每面 22 层 × 11 格；飘窗盒〔窗台/顶板/两侧封板/外端玻璃/滴水线〕外凸 0.42m、外缘贴齐退线；约 22% 窗格暖光点亮、约 55% 飘窗带窗台花箱）；
  - 72 屋顶为空中露台（一圈栏杆）；72–78m 空中会所玻璃盒；
  - 78–96m 顶部**「灯阁」**：塔身收分为一座四面暖光格栅灯窗的方阁（灯窗 + 窗棂 + 金属挑檐顶板 + 冠灯 + 天线）——白天是塔顶标志、夜间化作 96m 高空一盏暖阁，呼应「望湖阁」之名与「窗灯」母题。
- **裙房（南端，2 层 9m，15.6×15.6）**：东、南、西三面连续临街橱窗（玻璃 + 密梃 + 暖光），西立面为餐饮主面；9m 顶板可上人**屋顶花园**（木甲板 + 草皮 + 灌木 + 盆栽 + 一圈栏杆 + 露台桌椅）。
- **塔楼—裙房连接**：约 4.6m 金属格栅顶连廊，整合体量、形成落客灰空间。

## 续建 · 2026-09-27 立面观感提亮（应城主《街区观感同步》信）

- **背景**：首建时网页查看器尚无环境反射贴图（IBL），高金属度深色幕墙（玻璃 `#22344C` metalness 0.55）被额外压暗；城主信指出白天日光下望湖阁整体暗于同街区其余四栋。渲染端 IBL 修复后，先重跑 shot 自评确认现状：塔身确为深蓝黑玻璃主导的深色密窗网格、空中会所玻璃盒几近全黑。
- **决策（城主授权「是否调整、调整多少由你决定」）**：保留飘窗灯幕墙形制与花箱等全部「家」的叙事构件，只做材质换装——**深蓝黑玻璃 → 天青浅蓝反射玻璃**，配方与官方新件 `glassCurtain` 同一语言（PALETTE 11 号 `#9EC5DD`、metalness 0.5、roughness 0.18、emissive `#C4DFF0` × 0.3 兜底）；大堂落地玻璃用深半档的中青蓝 `#7FA6C0` 保基座稳重；金属件 metalness 0.5–0.6 → 0.3 回归中灰本色。
- **日夜权衡**：白天塔身透亮、会所黑盒消除、与暖黄顶阁成冷暖呼应；夜间暗窗由近黑转为深青底（反射城市夜光的真实状态），亮窗 emissive 1.35 对暗底 0.3 仍有 4.5 倍差，「万家灯火」对比度与顶阁暖光均保住。三环境 shot（day/dusk/night）自评通过。
- **积木兼容**：本人 `litgrid` 积木仅新增可选参数 `glassEmissive` / `glassEmissiveIntensity`（默认值保持老观感）——湖院、南门公寓不传新参，观感零变化；本次只动望湖阁一栋。
- **几何零增删**：inspect 实测仍 134,452 三角形 / 7,658 mesh，预算分配表不变。

## 续建 · 2026-09-27 二次调校：浅青方案否决，回归深玻璃白框（对齐南灯公寓）

- **城主网页实测反馈**：上一轮浅青换装在网页查看器 IBL 下「白灰蒙蒙一片」——浅青玻璃与浅框明度接近、对比不足；城主指定参照同街区**南灯公寓**（深玻璃 + 白色结构框，干净利落）改成同款风格。教训：配色观感以网页 IBL 实测为准，shot 软件光栅对高金属深玻璃偏黑、不能替代网页判断。
- **调整（材质回退 + 对齐南灯配方）**：
  - 塔身四面 litgrid 去掉浅青传参，恢复积木默认——`#22344C` 深蓝灰玻璃（metalness 0.55）+ 浅米灰框 `#D9D5CC`，与南灯公寓塔身完全同款；IBL 反射让深玻璃呈有层次的深蓝灰、不再死黑；
  - 会所 / 裙房橱窗等独立玻璃件由 matGlass 统一为南灯公寓同款 `#26405C`（比最初版 `#22344C` 独立件略浅一档，全城我名下建筑玻璃语言一致）；
  - 大堂落地玻璃恢复 `#1B2C42` 深色，衬托暖光大门与内顶光盒；金属件 metalness 恢复 0.5–0.6。
- **验证**：headless Chrome 直开网页 `?block=F4` 截图确认——望湖阁与南灯公寓并排同为深蓝灰玻璃+白框强对比，灰白蒙消除；inspect 全绿，几何零增删（134,452 三角形 / 7,658 mesh）。
