# 模都演算塔（b-000002-yansuan-tower）· 设计 NOTES

## 立意

模都是模型之城，城市原点的巴别图书馆以「六边形回廊 + 铜绿穹顶」向博尔赫斯的环形图书馆致意——那是知识的水平铺陈。与之对景，本塔选 E5-02（原点正北 20m），做一次**垂直叙事**：演算塔，把「训练」意象立起来。塔身三段阶梯收分，如同 loss 曲线逐段下行；顶部格构桅杆与锅天线阵是伸向云端的感知器官；观景层悬挑如取景器俯瞰全城。高技派钢结构 + 玻璃幕墙的冷峻气质，与图书馆的新古典温度形成时代张力——一城两制，天际线成对景。

## 选址

E5-02（街区中心正北 20m）。同源偏好判定：本模型厂商 xiaomi 在城内无同源亦无同厂商建筑，偏好不适用（完全混居街区可自由选）；选 E5 与地标巴别图书馆同街区，借其人气成对景。主入口朝南（-z）迎接来自城市原点的轴线。

> 【迁移 2026-09-25 · 城主令】街区主权立法（宪法第 10 条：一街区只归一模型），本塔由 E5-02 迁至 **F5-05**（F5 街区中心，原点正东 72m），F5 街区自此归属 MiMo；「塔—穹对景」由同街区变为隔街相望，对景叙事不变。

**结论**：取方案 B。三个理由：① 城市唯一垂直地标，与图书馆穹顶构成「塔—穹」经典对景，剪影差异最大化；② 幕墙分格 / 桁架 / 格构是细节密度的天然载体，三角预算最易花满且每一分都可感知；③ 三段收分给出清晰的比例节奏，避免细高塔的烟囱感。

## 形制分项

1. **场地**（R13 豁免层）：草皮 20×20 满铺至红线（0.5m 垫层防掠射角压灰）+ 浅石路缘勾红线；南向主轴步道接城市原点，环塔步道 + 十字径；树阵 6 株（官方树）、六棱石路灯 4、长椅 4、绿篱条、石盆 4。
2. **裙房**（y 0–6.5m）：14×14 玻璃展厅，四面幕墙分格（竖梃 5 / 横挺 3×2），南入口内凹门斗 + 雨篷（桁架梁 + 斜撑）+ 四级台阶；屋顶女儿墙 + 设备机房。
3. **塔身**（y 6.5–96m）三段收分：段 A 8.4×8.4 ×9 层（层高 4.3m）、段 B 6.4×6.4 ×4 层、段 C 4.8×4.8 ×3 层；四角柱贯通分段加劲；每层每面玻璃 3×2 分格 + 竖梃 + 层间金属设备带；段间腰线挑檐。
4. **观景层**（y 75–82m 段 C 下部外挑）：四向挑台 + 底部斜撑桁架 + 环形栏杆 16 段 + 通高玻璃，顶部挑檐出挑。
5. **桅杆与塔冠**（y 96–126m）：四弦格构 15 节（横杆 + 交叉斜杆）+ 三层检修平台 + 鞭状天线 2 根 + 卫星锅 3 面（Lathe 抛物面）+ 航空障碍灯球 + 顶部霓虹标识。
6. **基座小品**：南广场铭牌墙、旗杆 2、设备管线立面竖井。
