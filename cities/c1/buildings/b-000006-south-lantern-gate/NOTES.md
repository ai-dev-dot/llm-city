# 南灯公寓 South Lantern Gate · 施工 NOTES

> F4 灯花栖居街区四期（收官期）。望湖阁是阁上一盏灯，南灯公寓是门楣一盏灯——模都的南门在此入夜。

## 立意

名「南灯公寓」：南是街区南门，灯是窗灯母题，双关即在「南门的灯」。与望湖阁为 96m 高空的豪宅灯阁不同，南灯公寓为**城市新手家庭**而建——更小的飘窗、更亲切的尺度、楼下买面包上楼的日常。基座两层街角商铺沿南/东街连续展开（面包房·暖黄、便利店·墨绿、小酒馆·暗红），骑楼柱廊遮雨；东南角 45° 切角让出一处街角小广场，公寓主入口朝东南洞开，台阶、雨棚、暖光大门。45m 板顶是邻里共享露台（木甲板/草皮/盆栽/桌椅），露台东南竖起一座四面暖光格栅灯窗的**南门灯亭**（黛色金属四坡顶 + 冠灯）——夜间南街远望，如门楣悬灯；与一期望湖阁高空灯阁一高一低、一南一北呼应，「阁上一盏、门楣一盏」。

## 方案比选（三案）

| 案 | 构图 | 优 | 劣 | 取舍 |
|---|---|---|---|---|
| **A** | **切角门塔**：16×16 基座东南角 45° 切角，街角入口广场，上部塔延续切角，顶部灯亭镇守切角轴 | 街角标志性最强、「南门」感足；让出街角广场；与望湖阁方塔成差异 | 切角损耗户型、交接构件多 | **取** |
| B | **骑楼基座 + 规整方塔**：基座满铺、南东骑楼连续商铺，上部 14×14 方塔 + 顶亭 | 商业界面连续、塔座主从清楚、最「公寓」 | 较常规，标志全赖顶亭；与望湖阁裙楼+塔楼语汇略重复 | 不单独取，吸收其**骑楼柱廊与连续店面** |
| C | **L 翼 + 西北高塔**：南/东 6–7 层翼展，45m 薄塔退西北角 | 沿街面舒展、朝庭院友好 | 高塔贴临与邻地裙房夹击庭院；南门标志移到西北角，名实不符；偏离总图「南门楼收住东南」 | 否，仅吸收其**西北朝庭院绿化开口** |

**结论**：取 **A** 为骨——基座两层商业（切角五边形，南/东骑楼柱廊 + 三店），上部 12 层飘窗塔（四面 litgrid，南/东为尊），切角斜边每两层挂转角阳台；45m 屋顶邻里露台 + 南门灯亭（45–50.2m，冠灯/天线至 51.5m，细件上浮沿望湖阁 90→96 先例）。西北角对中央庭院做草皮绿化角与坐凳。

## 形制分项

- **场地（宗地 20×20m，全域场地设计）**：基底满铺；南/东环带 0.5m 方格步行砖错缝；切角广场斜边外区域同材铺装；北环带（对接望湖阁南环带）、西环带（对接市集东环带）暖色铺装薄板；西北角 6×6 草皮角 + 盆栽 + 坐凳，朝中央庭院开口。
- **基座（2 层，五边形 s=16 c=3.5，顶板 9m）**：
  - 首层南/东**骑楼柱廊**（圆柱 + 柱帽，柱列距街 2m）；廊后三家店：面包房（南西，暖黄招牌 + 米白布篷）、便利店（南东，墨绿招牌）、小酒馆（东南，暗红招牌）——橱窗玻璃 + 密梃 + 暖光门 + 招牌板 + 斜布篷；
  - 切角斜边（外法线东南）：公寓主入口——双开玻璃木门（门内暖光）+ 金属雨棚 + 壁灯 + 3 级台阶，入口两侧大堂玻璃窗；
  - 西、北白墙：后勤门、高窗带、贴墙爬藤花架；
  - 二层南/东连续橱窗带（密梃玻璃 + 上下线脚），西/北白墙高窗，切角斜边同做斜窗带；4.5m 与 9m 五边形楼板。
- **塔（9–45m，12 层 ×3m，五边形 s=14.4 c=3）**：每层五边形楼板 + 5 角柱；四面飘窗灯幕墙（私人积木 litgrid：南/东 w=11.4、西/北 w=14.4，飘窗外凸 0.42、外缘贴 7.2 退线，约 22% 暖光窗、过半窗台花箱）；切角斜边每 2 层一座转角阳台（挑板 + 玻璃门 + 三面金属栏杆）。
- **屋顶（45m）**：邻里露台——木甲板条板、草皮两带、盆栽、圆桌凳两组、五段外缘栏杆；东南切角轴立**南门灯亭**（台座 + 四角金属柱 + 四面暖光格栅灯窗 + 黛色金属四坡挑檐 + 冠灯 + 天线）；西北侧设备机房（白盒 + 百页门）+ 2×4 太阳能板阵列。
- **景观**：南/东行道树 4（树池）、切角广场造型小树 1、路灯 8、街角矮灯柱 2、石盆花钵 2、外摆伞 + 桌椅 1 组。
