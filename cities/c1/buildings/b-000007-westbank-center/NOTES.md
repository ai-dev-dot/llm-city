## 立意

名「西岸中心」：西是镜湖之西，岸是公园之滨，中心是街区的商业主塔。城市功能配比至今有工作（E5）、自然（E4）、归家（F4），缺**消费与烟火**——本塔补商业环：底层东面**骑楼拱廊**（8 段拱墙柱廊，檐下可停）串 8 开间橱窗（暖光展台 + 彩色招牌 + 遮阳篷），2–4 层密梃幕墙办公楼面挂竖向装饰鳍；北面主入口玻璃雨棚 + 发光门楣；西面临街做大堂通高玻璃与竖向招牌塔；南面绿墙格栅接三期公园经济带。塔身 20 层退台收分（16.8→60.3 全断面、60.3→74.8 收分），四面格构幕墙逐格带水平遮阳片，入夜玻璃透暖、冠部金环灯带 + 顶灯，与 F4 窗灯、E5 圆环构成「工作—自然—归家—消费」灯之四叠。裙房顶南段做**屋顶花园**（廊架/花岛/树/坐凳），退台露台环栏杆绿篱。

## 方案比选（三案）

| 案 | 构图 | 优 | 劣 | 取舍 |
|---|---|---|---|---|
| **A** | **橱窗阶梯塔**：裙房满铺 15×35 四层、塔居北段逐段退台，东向层层面对镜湖，屋顶花园在裙房南段 | 退台正对园景、屋顶花园南接三期、立面四面均可做密细节 | 体量偏正统 | **取** |
| B | **竖筒双板**：东西两片板楼错位，中部玻璃中庭贯通 | 中庭采光好、平面效率 | 板楼对公园面窄、天际线单薄，与 F4 板式住宅语汇撞车 | 否 |
| C | **角塔沿园展开**：塔缩至东北角、裙房沿东园长条展开为步行商业 | 商业界面最长 | 塔不成气候、总图「制高点」落空；长条裙房超核心进深 | 否，吸收其**东面连续商业橱窗** |

**结论**：取 **A** 为骨、吸收 C 的东面连续橱窗与 B 的中庭采光概念（北面大堂通高玻璃）——裙房四层 + 北段退台塔 + 南段屋顶花园。

## 形制分项

- **场地（宗地 20×40m 全域场地设计）**：草皮满铺至四边；东环带 2.45m 细拼花（临园，0.42m 错缝跳色）+ 树池格栅树阵 4 + 路灯 3 + 朝园坐凳 4；西环带同款拼花 + 街树 4 + 路灯 3 + 等侯凳 3；南北环带 0.5m 砖 + 街树/路灯；入口石盆 2、绿篱七段沿本体四周留口。
- **底层骑楼（东，临园主立面）**：8 段拱墙柱廊（拱 3.3×3.6 洞开到底）+ 拱后 8 开间橱窗（3.8m 大玻璃密框、店内暖光衬板、展台、发光招牌、布篷挑 0.62m 不穿拱）。
- **裙房 2–4 层**：四面密梃幕墙（8/5 开间 ×3 层，subCols3×subRows2 + 层间铝板带 + 每格遮阳片）+ 东面竖向装饰鳍 9 道；每层环通檐口线脚。
- **北立面**：主入口台阶 + 玻璃雨棚（挑至 z17.9 退线内）+ 双门暖光大堂 + 发光门楣 + 两侧橱窗接二期骑楼街。
- **西立面**：底层办公大堂通高玻璃 + 次入口 + 竖向招牌灯箱（青色 11.5m）+ 南段设备百叶。
- **南立面**：绿墙 + 双块窗棂格栅 + 服务门，接三期公园经济带。
- **塔楼（段 A 16.8–60.3 / 段 B 60.3–74.8）**：四面格构幕墙 20 层（cols 9–11 × rows 15/5，subCols2×subRows3 + 每格遮阳片 + 层间带），四角通长铝线条脚，60.3m 退台露台（环铺 + 四面栏杆 + 绿篱树）。
- **塔冠（74.8–87.7）**：格栅檐竖条 44 + 暖金灯带环 + 压顶 + 三节天线桅杆 + 顶红航空灯。
- **裙房设备层**：塔周围百叶围合 + 冷却塔造型，屋顶花园（13.4×17.6 拼花 + 双草皮岛 + 木廊架 + 栏杆环 + 树 4 / 凳 4 / 篱 3 / 石盆 2 / 灯 2）。
