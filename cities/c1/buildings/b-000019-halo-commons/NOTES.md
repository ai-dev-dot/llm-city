# b-000019 · 光环广场 Halo Commons

E5「原点街区」二期市民南广场——城市客厅，原点塔脚公共空间序列的第二段。

## 立意

**「原点三重奏」的地面终章**：E5 的母题是圆环/原点——原点塔的心脏是下沉原点光庭（原点本体在此发光），塔顶悬着发光原点环（原点升上天空）；本广场把原点放回地面：**一圈涟漪**。中心原点盘是落水点，环形镜水是最强一圈波纹，柱廊环是荡开的水痕，同心铺装涟漪一直荡到宗地边界——「第一栋楼落成时，城市从这里荡开」。

市民体验：从南面城市道路进入，金色子午线引导北行，穿过树阵客厅，眼前是微下沉的光环广场——弧阶可坐（级高 0.42m 恰为坐高），水环倒映 200m 原点塔与塔冠金环，环形银柱廊围合出没有墙的城市客厅；夜间中心盘、池底灯带、柱冠光环次第亮起，地面一个光环、天上一个光环，隔空对望。东翼树阵下散置三颗镜面圆珠（球=三维的圆），把塔、云和人都收进曲面——CBD 白领与市民的日常打卡点。

**形制分项**：

- **光环核心**（中心局部 C=(-9,0)，沿原点正南轴线）：微下沉圆广场——2 级弧阶（各宽 0.64、级高 0.42=坐高，96 分段，N/S/E/W 四方位 3m 宽人行口）+ 底盘 r3.9（y=-0.84）；中心**原点盘** r1.5 发光 + 双金环 + 24 放射刻度 + 外圈 3 环旱喷格栅与喷口阵。
- **环形镜水**：annulus r4.3~5.6 浅镜池（壁顶高出地面 0.12，四方位 2m 缺口做人行口），池内涌泉阵、池底灯带、马赛克砖底；镜面倒映塔身与塔冠金环。
- **柱廊环**：r7.6 环形银柱列（~25 柱 h3.6，础/冠齐备，四口对位）+ 主环梁双道 + 一圈细金线副梁（金点睛，呼应塔冠金边）+ 柱间银肋竖杆（塔身银肋语言延续）+ 柱冠下缘发光环；r6.4 环形木质坐墙四段（与柱廊同步留口）。
- **涟漪铺装**：以 C 为心的同心环带（三色花岗岩交替）+ 立体窄缝环（Torus 凹缝）逐圈外荡至 r17.6；内核环道 24 放射刻度缝；金色子午线（x=-10，原点轴线）宽 0.9 南北贯穿，北接塔前广场、南出城市界面。
- **东翼树阵客厅**（x∈[0,19]）：4×2 树阵（gardenTree+树池坐凳）+ 方格缝铺装与涟漪叠加 + **三颗镜面圆珠**（r0.75/1.05/1.4 对角渐大，高金属亮银）+ 长凳两组 + 树下地灯。
- **西带**：x∈[-20,-17.6] 草皮+步道+4 树，衔接塔宗地西环带语言。
- **灯光**：中心盘强光→金环→池底灯带→涌泉微光→柱冠光环→环梁灯带→涟漪灯阵（三圈矮柱灯 8+12+16）→广场周界 modernLamp×8——夜间自内向外层层晕开，与「夜间有灯」的街区性格一致。

## 施工记录

- **一轮（2026-09-28，zcode / glm-5.3）**：首建 + 自评迭代。inspect 排障三处：①涟漪缝环/柱廊环梁/坐墙/金线灯带等 `arcTorus` 件漏核心中心偏移（画在局部原点致 R2 超界 46×34m）——统一补 C 偏移；②涟漪圈 r 最大 17 但宗地 z 向仅 ±10——新增 `rippleSegs()` 解析裁剪（圆与宗地矩形求交：z 界截东/西带、西带再被西界截），裁剪角按外缘 r1 计防环带角部越界，R2 收敛至 39.9×20.0；③树池灌木散点半径内收（R13 曾超 0.25m）。四口断开逻辑 `gapSegs()` 用切点配对算法（西口跨 ±π，线性顺扫会漏半口）。shot 视觉模型自评（aerial/top 昼夜）一轮迭代：镜珠走位挪树阵网格中线（与树池/长凳穿模消除）、树灯改背离中线向、涟漪环带三色循环 + 缝环加粗 0.045→0.06（明暗节奏确立）、两级弧阶明暗交替（下沉可读性）、水面提亮 #4E86A0、树冠 scale 1.25/1.1→1.1/0.95。R1–R15 全绿：**152,664 三角 / 340 mesh / 高 4.6m**。夜景自评：中心原点盘焦点成立、灯光自内向外晕开层次可读（柱影遮挡为 shot 软渲染固有，网页端 IBL 无此问题）。token 统计不可得记 null（宪法第 6 条如实）。
