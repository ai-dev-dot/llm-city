# 算芯楼 · 求索智谷街区二期 — 设计文档

## 立项（城主确认实录）

- **2026-10-02 轻量立项门**：按街区总图 `cities/c1/blockplans/G5.md` **二期**，于宗地 **G5-03+06**（东北 1×2，20×40m）落建「算芯楼·智算中心」，呈报本栋立意（塔是笔尖、芯是墨池；一竖一横互文；格栅=算力阵列；夜间隔栅缝蓝光呼吸=算力心跳）。城主批复：**「批准，按总图开工（推荐）」**——立意不偏离总图二期「算芯楼·智算中心——服务器阵列意象格栅立面 + 冷却塔列 + 蓝色呼吸灯带，西接一期裙房」，依法开工。

## 立意

求索塔立「求索」之志（塔是笔尖），算芯楼行「创造」之实（芯是墨池）——想法在此变成代码，代码在算力上亮起来。**剖面叙事：数据自西缘 Data Stream 光带流入 → 门厅汇入光井 → 分两翼进入机柜大厅运算（立面灯阵呼吸）→ 热量经屋顶冷却塔与散热鳍排出 → 蓝光沿东缘回流。** 一竖一横互文：塔身螺旋是求索路径，算芯楼横格栅是算力阵列。兑现街区母题「求索·算光·∞」与「城市睡着时、智谷醒着」：昼是冷静的银格栅设备群，夜是整面呼吸的蓝色算光崖壁 + 中部通高「光之井」。

## 形制分项

- **场地（20×40 满铺至红线）**：草皮满铺 + 西园区接口带（6×16 铺装延伸至宗地西缘，接一期东侧绿化）与门厅前 4×10 站台；**Data Stream 数据流**——两排正弦波蓝光点自宗地西缘 x=-9.9 汇入门阶，东缘 x=+9.4 回流两排光点，夜为「输入—输出」双流；东带「运算闲庭」砾石铺装 + 树阵；北带绿篱 5 段（对 F4 街）+ 树 5 株；南带树阵对 G6 预留轴线；树阵共 26 株浓荫树；石球灯、坐凳、街灯、植槽按园区节奏布置；东南角「0/1 二进制音阶」雕塑（7 蓝 + 7 石墨方块错落，无穷母题的数字化）。
- **两段机柜大厅（各 15.6×13.3×12.9m，分踞 z=+11 与 z=-11）**：石墨深色芯体 + 0.6m 高勒脚 + 顶沿压边；三层带意象立面（y=1.5–4.3 / 4.6–8.6 / 8.9–12.55）——每带亮青玻璃底 + 8 根冷银竖格栅（外挑 0.17）+ 带顶横梃 + 层间蓝灯带 + 白/蓝状态灯珠 4 颗；东立面（对 H5）14 跨、北/南山墙各 6 跨为格栅主面；西立面（对一期裙房）用官方 glassCurtain 密梃幕墙 columns 16 rows 9 整面透亮 + 内景 3 条暖光机柜灯带——「接口面」与一期裙房幕墙同源。
- **光井（z=-4.4~4.4，通高 13.9m）**：四角钢柱 + 四面官方密梃玻璃幕墙（东西 15.6 宽 cols 12 rows 6、南北 8.4 宽 cols 6 rows 6）；y=8.3 一道玻璃连桥横跨（板 + 双栏杆 + 桥底蓝灯条）；底层玻璃庭院——水盘涌泉（3 束喷流 + 水下蓝光环）+ 4 根暖光柱 + 1 株庭树 + 坐凳；顶部光冠——4 条蓝光框 + 斜切玻璃顶棚 + 冠顶灯珠，夜为街区第二灯点（亮度仅次于塔冠算力之眼）。
- **屋顶（南段）冷却塔列 ×5**：锥筒塔身 3.1m（上 1.18 下 0.95、22 段）+ 顶扩喇叭环 + 双腰箍 + 竖肋 8 条 + 顶部水平格栅 + 蓝顶灯，沿 z=-11 一字排开，「散热」母题实体化；
- **屋顶（北段）散热鳍组 ×10**：石墨底座 + 8 片竖银鳍 + 顶部横管，2 排 5 组阵列；两段屋顶各四周官方栏杆女儿墙 + 检修薄板步道 + 天窗带（南段 2 条发光玻璃天窗）。
- **入口（光井西侧，对一期）**：门厅西面玻璃内凹 0.9m，3 级薄板台阶（全收于本体红线内）+ 悬挑雨棚 + 门头蓝光刻线 6 条 + 光井玻璃下暖光内衬。
- **材质**：延续街区银蓝科技风——亮青玻璃 #9EC5DD（metal 0.5 / rough 0.18 / emissive #C4DFF0 0.3）、冷银铝 #B8BCC2、石墨 #2A2E33、算力蓝 #3FA9F5（emissive 2.0）、暖灯 #FFE9A8、冷却塔白 #E8E6E1。所有随机走 `ctx.rng()`。
