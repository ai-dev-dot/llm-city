## 立意

《云阶之上，一梯一户》。揽月大酒店的居住续章：酒店给城市一扇窗的巅峰（登堂），揽月阁给少数人一整层云（入室）。大平层层层退台——每户一整层、层层有退台花园；同族石材竖梃 + 香槟铜续街区族谱，冠部小穹顶亭 + 小月牙（r1.2，对主塔月牙保持克制从属）。南望 F4 灯花（一千扇窗的家）、西对一期映月池前庭（街区礼仪轴）、东望 G3 留白（呼吸）。与 F4 望湖阁（社区高端住宅）错位：那边是温暖的家，这边是城市巅峰的私邸——全城唯一「酒店管家服务的云顶大平层」。

## 设计

### 方案比选（三案）

- **案 A 四段退台云阶塔（选定）**：15.2²→13.8²→12.4²→10.8² 四段内收（段差 0.7m/边出戏剧环台），段间退台成环形花园（绿篱环 + 角树花钵 + 段顶洗墙灯环——云阶夜景分层点亮）——「层层退台」落实总图描述，云阶轮廓与主塔冠部退台呼应成族；每户一整层 360° 环窗。
- **案 B 双板错位塔**：两块 12 层板楼上下错位旋转 90°——现代感强，但与街区「经典顶奢」族谱断裂，且 20×20 宗地内双板拥挤。
- **案 C 直筒塔 + 顶部退台**（主塔同款三段式缩小）：族谱最齐但无辨识度——揽月阁需要自己的表情（云阶退台 = 居住感），不宜做「小一号主塔」。

结论：案 A。云阶退台既是功能（层层花园）也是剪影（与主塔「一顶穹月」对「四阶登云」），主从分明。

### 形制分项

- **场地**（20×20 满设计）：草皮满铺 ±10；月相步道环带（12 块石板续一期序列相位）；东南角「小水中月」静水方池 + 三石凳；树 6 株 + 绿篱带 + 路灯石盆；落客车道自南路引入转西入口。
- **基座**（2 层 8m，15.2²）：勒脚凹槽石；首层拱窗 11 扇（七成内透，西面让位主入口）；二层竖梃宽窗；齿饰檐口 + 暖金洗墙；西主入口双石柱门廊 + 铜檐 + 小月牙徽记（r0.6）+ 三级台阶。
- **塔身**（17 层四段云阶，8→67.5m）：每面 4 梃 3 宽窗（2.5m 落地宽玻，云顶段加大 2.8m），四成夜窗；每层通长铜栏阳台（细柱 + 双横杆）；每段段顶铜线脚 + 退台环形花园（通长栏板 + 四角花钵）。
- **冠部**（67.5→~76m）：会所环厅（石柱 8 + 暖光内透）→ 穹顶亭（8 小柱 + 铜金半球 + 4 经肋）→ 小月牙尖（r1.2 自发光，主塔伴月）。

### 迭代实录（shot 自评 → 修正）

- 段差 0.5→0.7m/边：直筒感转四段云阶剪影。
- 段顶加洗墙灯环：云阶夜景分层点亮（「登云」的夜读）。
- 退台花园落绿篱环 + 角树（官方 hedge 无 y 参数，退台件自绘）。
- 实测通高 78.1m（总图约数 ~75m 上沿），甘居主塔 ~108m 之下。
