# b-000023 · 镜湖倒影湖 Mirror Lake

E4 镜湖中央公园「温室之心」街区总图**二期地景**——CBD 正北的呼吸孔：一片把原点塔北立面收进水面的静镜。

## 立项（宪法第 12/13 条 · 街区总图轻量门）

- **依据总图**：`cities/c1/blockplans/E4.md`（案一·温室之心，城主 2026-09-29 批准）。本栋为总图**二期**。
- **2026-09-29 轻量立项**：按总图二期于宗地 **E4-07+08（南排西二 1×2，40×20m，正对原点塔）** 建「镜湖倒影湖」——硬质南岸 + 低粗糙度镜面水体 + 拱步桥 + 百花坛，把原点塔北立面收进湖面取景，兑现 D4/F4 临湖/临园对景。**城主会话明令「继续二期镜湖倒影湖」**，不偏离总图二期功能分配与「零高度地景（≤2m 桥/栏）」档位，按图落宗执行。
- 立意：一期给了绿肺一颗发光心脏（穹），二期给它一面镜子（镜）——南北中轴把「温室穹顶—镜湖—原点塔」串成一条视线，人立北岸平台南望，塔影落湖。

**选定甲案**。

## 形制分项

- **镜面湖**：30×12m 矩形静水，四边石造池壁 + 压顶石梁；水面细分 240×96 带正弦微涟漪 + 顶点色深浅，低粗糙度（0.06）+ 微自发光（入夜泛幽蓝）。
- **睡莲**：40 组叶盘 + 半数荷花点缀水面（让开中轴桥洞）。
- **拱步桥**：中轴南北向、跨全湖的单孔石拱——28 段弧形桥面 + 两侧栏板扶手 + 14 对望柱 + 桥下两道半圆拱肋 + 两头抱鼓石与石狮墩；顶高 ≤2m，为全栋唯一「本体」（R13 校验落 ±18×±8）。
- **百花坛**：南岸主坛（26×1.8）+ 北岸副坛，密植数百朵六色小花（茎 + 二十面体花冠，微自发光），硬质南岸石栏 + 14 只石盆列阵。
- **芦苇湿地**：四角各一丛 14 支锥形芦苇。
- **环湖树阵灯柱**：10 株环湖树 + 8 灯柱 + 4 长椅 + 中轴 12 只发光地灯（把「塔视线」铺成一条光带引向原点塔）。
- **场地**：细分带微起伏的顶色铺装/草皮，铺满至宗地四边。
