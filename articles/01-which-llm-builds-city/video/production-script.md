# 模都第一期 · 横屏视频制作脚本

## 制作口径

- 画幅：**16:9 横屏**，建议成片 1920×1080、30fps。
- 计划时长：**2 分 59 秒**。下表是剪辑预排时间，尚未录音；正式剪辑以自然口播为准，在 2–3 分钟内微调。
- 台词：采用同目录 `voiceover-v1.md` 的第三稿，逐字保留。九个街区顺序：**G5 → D5 → E7 → D4 → F4 → E4 → E5 → E6 → E3**。
- 形式：旁白配城市实景。模型第一次出现时标明完整版本，镜头跟着点评展示具体部位。
- 本次交付为制作脚本。**2026-10-03 后续工序已全部完成**：视频定稿发布（38 镜，预排时间轴被自然口播重排，成片 148.8s），封面/文案页齐；见同目录 README 与 spec.json。

## 横屏画面与声音

**版式。** 建筑画面占主体，左上放两行信息条：第一行是完整模型名，第二行是街区名。底部放逐句口播字幕。以 1080p 为基准，信息条距左、上边缘约 64px；字幕距底边约 70px，左右各留至少 120px。字幕建议 44–48px、白字配深色描边或半透明底，优先一行、最多两行；英文型号作为完整词组，必要时让整组换行。

**素材适配。** 当前绕飞素材是 640×427，接近 3:2；图片也不是统一横屏比例。默认等比完整放入 16:9 画布，余白用深灰背景，或同图放大、模糊、压暗垫底。不得为了铺满画面裁掉塔顶、站台或街区边缘。竖幅静态图可放左侧约 60% 的区域，右侧只放一句点评；需要对照细节时，再用右侧小窗展示同图局部。此布局适合现有低分辨率素材，不需要把每张图都强行放满屏。

**剪辑。** 街区之间以直切为主；同街区用「整体 → 细节 → 整体」串联。局部箭头、框线只在讲到该部位时出现，随后消失。静态图允许约 100%→108% 的缓慢推近，避免继续放大低清细节。编号只表达出场顺序，不做名次、评分或奖牌。

**口播。** 像带朋友看自己做的项目，语气自然，模型版本清楚读完。英文名称和数字不抢读；「湖呢？」稍停一下，再给湖的位置。负面评价保持聊天语气，不额外增加嘲讽词。

**声音。** 一条轻快、无歌词的背景音乐贯穿，以不影响听清英文型号为准。最多在楼顶大灯、湖位置标注出现时加很轻的提示音；不用每次切镜都加音效。结尾留约 1 秒画面，音乐自然淡出。音乐在实际制作时选用已获授权素材，本次不指定曲目。

## 高清补录建议与现有素材退路

现有素材足以做第一版剪辑，但尺寸偏小，GIF 只有有限帧率和调色板。导出1080p/30fps只统一交付格式，不会恢复高清细节或真实30帧运动。街区动图不需要反复循环来填满整段：表中已用静态图承接讲解。可使用的绕飞角度需要在实际剪辑时逐段挑选，本次未逐帧验收。

如果后续追求清晰成片，优先补以下镜头；这不是本次已执行的工作：

| 优先级 | 镜头 | 拍摄要求 | 暂不补录时 |
|---|---|---|---|
| 高 | E5 原点双塔 | 横屏完整收入塔顶与地面，保留双塔高低关系，约6–8秒稳定绕飞 | 从现有E5动图选择完整双塔帧；低清竖图只作备用 |
| 高 | G5 螺旋、D4 店面 | 各补一个中近景，分别看清螺旋与窗框店面，约5秒 | 原图框选位置，避免放大成糊块 |
| 高 | 全城及九个街区主镜头 | 每处8–10秒，横屏、慢速运动、建筑完整入画；网页真实帧率不足时降低运动速度 | 使用现有GIF，等比入画配静态图 |
| 中 | D5 绿化、E7 轨道、F4 灯、E4 湖、E6 剧院、E3 白墙与穹顶 | 每处补1–2个定机位或缓慢移动镜头，每个4–6秒；让点评对象在画内可辨认 | 使用对应静态图和箭头，已确认E4湖与F4顶灯在图中可见 |

补录网页实景时沿用仓库 `docs/shot-web.md` 的有头浏览器流程，不用无头WebGL、不另造截图工具；城主常驻5173服务保持原样，验证或补录另起端口。镜头素材等生成物落 `node_modules/.cache/llm-city/`，不把输出视频放入版本库。

## 后续制作顺序与交付检查

1. 先录一遍完整台词，按正常语速确认总长，再微调上述时间轴。若超过3分钟，优先收紧镜头停留和过渡，不擅自删台词、不把模型版本念得含混。
2. 按18段时间轴排画面，用原图和已有GIF即可先完成粗剪；高清补录沿用相同镜头位置替换。
3. 配好口播后生成逐句字幕并人工校对型号。不要把本脚本的预排时间当作已完成对齐的SRT。
4. 加信息条、部位标注与轻背景音乐，最后看一遍完整视频。

最终核对：横屏16:9；九个街区没有遗漏或串画面；前三个顺序为DeepSeek V4 Pro、Space Bunny、GLM 5.3 Flash；所有型号与台词一致，尤其区分GLM 5.3 / GLM 5.3 Flash、DeepSeek V4 Pro / DeepSeek V4.1 Flash；塔顶、列车、湖和大灯在对应台词处可见；没有额外增加结尾总结与开源引导；收尾原句为「以上这九个街区，你最喜欢哪个呢？评论区聊聊。」
